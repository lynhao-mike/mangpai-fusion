# T-198 · P1 真实案例录入 + 试跑（3–5 例）

- 状态：🔵 Ready（等案例）
- 依据：P0 报告；P1 模板；人类提供真实案例
- 前置：`META/p1-intake-template.md`

## 0. 一句话

收 3–5 个**有已知事实**的真实案例（截止 2026-10-30），按 P1 模板录入；
Agent 出卡+锚点题；人只答事实；留出事实评分。**没有事实的案例不进 P1。**

## 1. 输入

- 案例：`known_facts` 1–3 条、`holdout_facts` 1–2 条、问题、四柱/性别；
- 所有事实 ≤2026-10-30；锚点事实 ≠ 留出事实；
- 匿名化。

## 2. 任务

- **P1 收满 n=20 动态卡（12–15 盘）**；A 固定克/生/化/墓；B1 锚点；B2 专家；C 留白；
- **P1 指标（2026-10-30 三裁决冻结版）**：
  - A 只固定克/生/化/墓；精度 ≥95%；A 失误 ≤1；类外 0；引文 100%；
  - 候选池真值包含率 ≥85%（≥17/20）；B1 Top-2 ≥85%；Top-1 ≥75% 仅披露地板；
  - B1 McNemar 净胜 `b−c ≥4`、错误翻转 ≤1、单侧 `p<0.05`；n=10 只 smoke；
  - B2 仅 B1 锚点耗尽时启用：记录缺失事实、盲选随机顺序、2–3 候选带 source/quote；率目标 ≤15%、**硬上限 ≤30%**；
  - C≤25% pass、25–35% 只写“解决 X%”、>35% fail、>50% kill；unknown≤20% pass、20–30% 宣称、>30% fail、>50% kill；
  - 换盘移植拒绝率 ≥85%；
  - P1 一次判、最多一次迭代。

## 4. 边界

- 不读旧答案/旧 timing；不自动承诺冲/合/穿/刑；不扩岁运；
- 锚点事实不用于评分；P1 只判 pass/一次迭代/kill；
- P2 以 LOEO 为主，Event-First 仅已排期二元事件；禁流月全生命周期扫描；12–15 盘/30 事件；交换盘 kill；Brier 只做相对三对照；预注册 hash；≥10 可解析分支；P2 kill=换盘不显著、覆盖失败>20%、单一断语泄漏、事后改标签。
