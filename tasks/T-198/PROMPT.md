# T-198 · P1 真实案例录入 + 试跑（3–5 例）

- 状态：🔵 Ready（等案例）
- 依据：P0 报告；P1 模板；人类提供真实案例
- 前置：`META/p1-intake-template.md`

## 0. 一句话

收 3–5 个**有已知事实**的真实案例（截止 2026-10-30），按 P1 模板录入；
Agent 出卡+锚点题；人只答事实；留出事实评分。**没有事实的案例不进 P1。**

## 1. 输入

- 案例：`known_facts` 1–3 条、`holdout_facts` 1–2 条、问题、四柱/性别；
- 所有事实 ≤2026-10-30；锚点事实 ≠ 留出事实；
- 匿名化。

## 2. 任务

- 每例：`engine.cli` 事实；候选 2–3；锚点题 1–2；`engine_validation`；
- 人答事实；A/B1/B2/C；留出事实评分；
- **P1 指标（2026-10-30 裁决版）**：
  - A 只固定克/生/化/墓；精度 ≥95%；类外 0；引文 100%；
  - 候选召回 ≥80%；选择正确率 ≥80%；**按案例聚类**，不按事实条数；
  - B1 锚点 Top-2 真值包含 ≥85%；**删“定锚后 Top-1”**；
  - 净胜 `b−c ≥4` 且单侧 `p<0.05`，**仅 n≥20 判 pass**；n=10 只报方向；
  - C≤25%、unknown≤20% 为 coverage 门；C>35% 或 unknown>30% hard fail；
  - B2 仅在 B1 锚点耗尽时启用：记录缺失事实、盲选随机顺序、2–3 候选带 source/quote；B2 率只披露、目标 ≤15%；
  - P1 一次判、最多一次迭代。

## 3. 产物

- `META/p1-cards-v1.json` / `p1-report-v1.md`
- `tasks/T-198/BRIEF.md` + `STATUS.md`

## 4. 边界

- 不读旧答案/旧 timing；不自动承诺冲/合/穿/刑；不扩岁运；
- 锚点事实不用于评分；P1 只判 pass/一次迭代/kill；
- P2 以 LOEO 为主，event-first 仅已排期二元事件，取消流月全生命周期扫描；交换盘 kill；Brier 只报 BSS；≥20 事件、≥10 可解析分支；预注册阈值改动即作废。
