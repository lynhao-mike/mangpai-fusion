- 优先级：P0（批次 1 的前置）
- 创建：2026-10-26（中枢）；v2 同日修订
- 依据数据：`META/claim-condition-corpus-v1.json`（481 张带性别真实盘）

## 0. 上一版的错误

上一版把「造一个改了一个字的盘」当成「语义对比对」，并给它一个**我预设的期望结果**。那个期望结果是我编的，不是现实：假盘对应的人不存在，它的学历/婚姻结局无从得知。**那只能证明编译器符合我读句子的方式，不能证明断语成立。** 本版作废该用法。

## 1. 三类验证，各管各的问题

| 类别 | 用什么盘 | 能回答 | 不能回答 | 是否进准确率 |
|---|---|---|---|---|
| **A 命中率筛查** | 真实盘（481） | 这条条件是否过宽/过窄/原子失效 | 断语真假 | 否，是筛选门 |
| **B 真实自然对照** | 真实盘 + 真实结局 | 条件成立组与不成立组的结局是否有差异 | 因果（非随机分组） | 是，但要带样本量与混杂说明 |
| **C 编译器回归** | 合成盘 | IR 的 and/or/not 是否写对、改代码后是否漏触发 | 任何命理真假 | 否，是开发门禁 |

## 3. B 类：真实自然对照（本卡的主体）

### 3.1 做法

对每条断语，把 481 张真实盘分成两组：

```text
命中组 = state == candidate（条件全部成立）
对照组 = state == rejected（条件确定不成立）
```

然后比较两组的**真实结局分布**（学历三档 / 婚姻状态 / 财富层级）。不造盘、不改字、不预设答案。

### 3.2 指标

| 指标 | 定义 | 判读 |
|---|---|---|
| `n_hit` / `n_ctrl` | 两组样本量 | 任一组 < 8 直接判「不可判」 |
| `effect` | 结局比例的差值（如命中组本科率 − 对照组本科率） | 方向与断语一致为「支持」 |
| `ci95` | 差值的 95% 置信区间（Wilson / bootstrap） | 跨 0 判「不可判」 |
| `confounders` | 性别、年代、流派口径、命盘复杂度 | 必须列出，不得省略 |

### 3.3 结论只有三种

`支持` / `不支持`（方向相反且 CI 不跨 0）/ `不可判`（样本不足或 CI 跨 0）。**不允许写「有一定道理」。**

### 3.4 已知偏倚（必须写进报告）

不是随机分组：印星空亡组与不空组在日柱、旬、年龄上系统性不同。所以结论是**关联**，不是因果；且只能说明「这条条件在该库里有无区分力」。

## 4. C 类：编译器回归（合成盘，降级为门禁）

只做两件事，且**不产出任何准确率**：

1. 对每条 IR 的每个原子，注入桩事实翻转其真值，断言整条断语按布尔逻辑变化（抓 and/or/not 写反、否定词丢失）。
2. 对已确认的真实正例盘，改一个不相关字段后断言**仍然触发**（防重构漏触发）。

命名：`ir_fidelity`（IR 保真度），不叫 accuracy，不进 ADR-002 的交付分。

## 5. 顺序（重要）

```text
1. A 类筛查（已完成）→ 淘汰过宽/原子失效的断语，先把它们修好
2. 人工把 45 张「印星空亡」命中盘的学历读成三档标签（T-122）
3. B 类对照 → 出「支持 / 不支持 / 不可判」
4. C 类回归 → 每次改 IR 都跑，防退化
```

**先修 A 类暴露的三条**（M1-D-009 过宽、M3-R-166 原子失效、M1-D-298 过窄），修完再对照，否则对照的是坏条件。
