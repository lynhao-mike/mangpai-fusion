## 3. B 类：真实自然对照

### 3.1 分组

```text
命中组 = state == candidate
对照组 = state == rejected
```

**婚姻类断语必须按性别分层**（乾看财、坤看官杀，混算会互相抵消）；学历类可先不分层，但要在报告里注明。

### 3.2 学历标签（四档，用户 2026-10-26 定）

| 档 | 定义 |
|---|---|
| A | 小学及以下 |
| B | 初高中 / 技校 / 中专 |
| C | 大专 / 本科 |
| D | 研究生及以上 |

标注口径：以反馈文本里的**最高已取得学历**为准；只写「读书好/聪明」不算学历；写「中专后自考本科」按 C；写「初中辍学」按 B（辍学但学段在初中）。

### 3.3 指标

| 指标 | 定义 | 判读 |
|---|---|---|
| `n_hit` / `n_ctrl` | 两组样本量 | 任一组 < 8 → 「不可判」 |
| `effect` | 结局比例差（如命中组 C+D 占比 − 对照组 C+D 占比） | 方向与断语一致 = 支持 |
| `ci95` | 差值 95% 置信区间（Newcombe / bootstrap） | 跨 0 → 「不可判」 |
| `strata` | 性别分层后的各自结果 | 两层方向相反 → 必须分别报告，不得合并 |

结论只有三种：`支持` / `不支持` / `不可判`。不允许写「有一定道理」。

### 3.4 偏倚（必须写进报告）

不是随机分组：印星空亡组与不空组在日柱、旬、年代上系统性不同。结论是**关联**，不是因果。

## 4. 为什么 4 条要降级（A 类暴露的结构问题）

`engine/facts/structure_check.py` 的 `build_duan_zuogong_candidates` 只做两件事：静态十神→体用映射、找跨越体用的关系边，输出**候选**；文件自己写明「只列候选与宾主方位，**不计层数、不折算富贵**」。

段派真正的链条是四步：

```text
体用相交 → 制得住（克者得根得令、被制者无反克、无合解）→ 宾主归属（他宫之财被我制）→ 做功层数 → 富贵层级
```

引擎只有第 1 步。所以「命中 92%」是「存在克边的盘」的比例，与原文「80%」不是同一个量。**缺的原子：`zuogong_success(kind,target)` 与 `zuogong_layers`。**

同理，`engine/energy/zuogong.py` 明言「墓 = 简化实现，只检测财官入辰戌丑未」，所以 `ru_mu(食神)` 永远为假——不是数据问题，是事实层不覆盖。
