## 速度结论与可复用方法

**列表定位已有可复现的局部加速；整体提取速度是否稳定提升5倍仍未证实。**下列计时是已记录的列表定位批次，不是整期提取、核对和双文件保存的耗时；没有同口径旧方法基线，不能据此宣称整体倍数。

| 方法 | 已记录实测 | 结论 |
| --- | --- | --- |
| 连续Down 600次 | 20.84秒，约推进125期（约6.0期/秒） | 可靠的远距离定位基线之一 |
| 连续Down 900次 | 32.48秒，约推进182期（约5.6期/秒） | 与600键批次接近，但推进量随加载变化 |
| 连续Down 1300次 | 45.75秒，屏幕从1513推进到约1256（约257期）；另一次45.90秒，从1503推进到约1254（约249期） | 两次远距离批次相近，约5.4–5.6期/秒；仍以截图校准 |
| 连续Down 600次 | 22.29秒，屏幕到约1360；随后400次15.29秒到约1254 | 两批合计约37.6秒推进约259期，约6.9期/秒 |
| 连续Down 900次 | 33.44秒，从约1503到约1324 | 约5.4期/秒；与其他远距离批次量级接近 |
| Page_Down 80次，每4键停150ms | 6.74秒，约推进125期 | 单批快，边界可靠性不足 |
| Page_Down 65次，每4键停150ms | 5.56秒，约推进86期 | 单批快，边界可靠性不足 |
| Page_Down 140次，同样停顿 | 10.65秒，仅约推进50期后卡边界 | 不作为默认策略 |

判断：连续Down远距离实测约5.4–6.9期/秒，多批结果支持列表定位提速。接近目标和加载边界时速度会变化；本轮有一次1100键完全未移动，点按当前截图所示圆形箭头恢复列表后才继续。每批后观察屏幕，不能从按键次数推断期数。Page_Down单批较快但已实测停滞，不作为稳定方法。当前可以确认“列表定位提速”，不能确认“每期完整提取稳定提速5倍”。

操作要点：

1. 每次返回列表可能重置到较新的期数；先观察实际区间，不沿用旧定位点。
2. 如需回顶，先在当前截图确认右下圆形箭头，再点击。不要复用历史坐标。
3. 快速连续Down远距离分大批，接近目标缩小批次。按批次观察，不要每几键就截图或读取整棵文本树。当前续接目标是第1226期。

5. “没有更多了”可能是假终点；轻微向上（例如6次Up）再连续Down，必要时观察后回顶重新启动。
6. Page_Down仅可在已加载区段作为尝试，出现停滞立即回到Down流程，不重复消耗时间研究已失败的混合Up/Down/Page_Down方案。
