## 1. 冻结定义（任务卡 §2，预注册，不得中途改）

基础集：`duplicate_key` 全等去重（保留首次出现）+ `gender ∈ {男, 女}` + 出生日期可解析。`chart_ready` = 出生时刻可解析（只标记，不建盘）。

- **debt = 1**：任一**非提问** `income` 事件文本命中债务关键词。
- **debt = 0**：有 `income` 证据事件（非提问、非空文本），但零关键词命中。
- **debt = null**：无 `income` 证据事件（无该域事件 / 全是提问 / 无文本）→ 该域排除，**不折入 0 或 1**。
- **serious_health** 同构，域换成 `health`，关键词换成严重健康关键词。
- **1 优先**：同一案例既有命中事件又有未命中事件 → `1`（存在性标签），计数单列 `conflict`。
- **提问不算证据**：事件文本含 `？`、`?`、`是否`、`能否`、`请问`、`怎么样`、`吗`、`么`、`呢` 任一 → **整段**不作证据（字面子串匹配，不还原问句语义）。

债务关键词（原样冻结）：`负债`、`欠债`、`债务`、`欠款`、`借款`、`贷款`、`信贷`、`破产`、`被骗`、`还债`、`负债累累`、`亏损`、`资金链`、`被执行人`

严重健康关键词（原样冻结）：`手术`、`住院`、`ICU`、`抢救`、`病危`、`癌`、`肿瘤`、`重病`、`大病`、`慢性病`、`中风`、`心脏病`、`糖尿病`、`肾衰竭`、`化疗`、`放疗`、`瘫痪`、`失明`、`精神病`

> `polarity` 只随事件记录并参与审计，**不参与判定**：卡片 §2.2 / §2.3 是纯关键词规则。语料里「么」大量出现在「什么 / 怎么 / 这么」中，按字面规则一律先判提问；这个方向的误差只会把证据变成排除（null），不会把提问当证据。
