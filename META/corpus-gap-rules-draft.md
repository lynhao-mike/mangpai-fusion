## 缺口 3 · 流年引动对象 → 应事领域映射

**结论**：**部分新立条 + 部分语料无据**。拆成两半：

- **可立**：判定程序主条「先由被引动之星定应事领域，再在该领域内选规则定吉凶」——**原稿可读到**（锚点 A/B/C），立 `M2-Y-404`。
- **无据**：DIAG 建议的五条具象映射（印动=学业/单位、禄动=身体、妻星宫动=婚恋、杀库动=工作、比劫动=竞争人际）**不能作为一整张对照表回读到原文**。它们各自分散在不同原稿段落且原文本意多为「职业取向」或「心性/六亲」，不是流年引动的领域判定口诀。**明确判定：这五条具象映射为语料无据，不得立为规则。**

### A. 可立部分 · 判定程序主条

|---|---|
| **规则 ID** | `M2-Y-404`（新立，续号依据见下） |
| **一句话规则** | 先定被引动之星，再定应事领域，后选规则 |
| **前提条件** | ① **引动判定先行**：先列出该岁运实际引动了原局哪些星/宫（lifa 层：生克合冲破刑；engine 可检：凡与该岁运干支构成关系边且 scope 含 dayun/liunian 的 natal 成员）。② 引动必须是**实质加力**（透干/填实/引动），natal 已有的常态边不得算流年新增引动（DIAG-1 §六.7「常态边不入断」）。③ 领域按被引动之星的**十神含义**定（印=学历/单位/名声/房子、官=事业/工作变动/法律、禄=身体/俸禄、财=财富/妻、比劫=兄弟朋友竞争、食伤=技术/快乐/子女——各十神含义见 Y2「十神的含义」章 line:2126-2660）。④ 一星多领域时不并断，按命主所问之事**择主领域**（原口径：「看哪方面的事和灾，要看他代表的是什么」）。⑤ **几个星动就有几方面的事**：多星引动可多领域并应，但不得把多领域塞进单一吉凶断语。⑥ 领域定后才能选规则定吉凶；领域错配则该年断语整体无效（不做「领域内规则正确但领域错」的部分给分） |
| **滥用形态** | ① 跳过领域直接套吉凶断语（本轮最大病因：DIAG-1 §六.1「领域判定先行」正是针对此项）。② 只按流年干支五行断事，不看不引动哪个星。③ 把 natal 常态边（如群劫克财）当流年新增引动。④ 一星多领域时全部并断成「这一年什么都应」。⑤ 把本条当成映射表用（见下方「无据部分」）。⑥ 用领域判定替代力量/真假判断（原命真假、力量仍是前置，`M2-Y-349/300/301` 真假关不受本条豁免） |

### B. 无据部分 · DIAG 建议的五条具象映射（**判定为语料无据，不立条**）

DIAG-1 §五 缺口 3 的建议栏写的是「补一条裁决总纲规则（或写入 probe）：先由『流年引动哪个宫/星』定领域……」——**程序部分（上条 `M2-Y-404`）有据**；但建议栏括号里列的具象映射表：**印动=学业/单位、禄动=身体、妻星宫动=婚恋、杀库动=工作、比劫动=竞争人际**，我逐条回读的结果是：

| 具象映射 | 回读结果 | 原稿实际语义 |
|---|---|---|
| 印动 = 学业/单位 | **半有据，不可作领域判定口诀** | Y2 line:2300「# 十神正印」物象栏「学历、脸面、寿禄、思想、心情、房子、车，权力」，人象「母亲、领导、上司」；line:2310「家里的官生年上的印，也是吃皇粮的、既有学历有工作」。这是**十神物象/职业取向**，不是「印被引动即应学业」的流年断法 |
| 禄动 = 身体 | **半有据** | Y2 line:2682「禄是最宝贵的，它代表了生命，代表了俸禄、寿禄、荣华富贵」；line:2702「原命禄被晦、被克，一是命苦福浅、劳碌；二是行运让禄减力……主身体有疾病，工作事业不顺」；line:3369「女人的禄表示身体」。均已收录为既有规则（M2-Y-202 禄五忌等），且原文本意是**禄被克晦**才断病，不是「禄动即病」 |
| 妻星宫动 = 婚恋 | **有据但已在库** | 段派 `M1-D-291/292`（婚姻以配偶宫为主、星为辅）、`M1-D-295`（配偶宫与配偶星发生相关性都表示婚姻信息）、`M2-Y-387/388`（宫为主星为辅、夫妻宫忌刑冲克破穿合去）。**婚恋领域已有成体系覆盖**，只是散在婚姻类规则里，不是「缺口」 |

**结论**：五条具象映射的**语义原料**散见于既有规则（多为十神物象或条件句），但**没有一条原文把它们表述为「流年引动 X ⇒ 应事领域 Y」的判定表**。若按 DIAG 括号里的形态立条，就是把「十神物象/职业取向」改写成「流年引动领域判定」，属自创口诀。**故判定为语料无据，不立条**；建议把这五条降级为 probe 中的**提示性核对清单**（提醒 Agent「该年被引动的星有这些物象，需辨主领域」），并在 probe 中明确标注为「由十神物象推得的提示，非流年断语」。

### 为何判定为缺口（部分）而非已有覆盖

- 程序主条：`META/rule-attribution-index.md` 全文检索「观动静」「穿在什么星」「应在哪方面」「哪方面的事」「动静」均**无成条**（仅有 G-SP-120「壬癸动静成对取象」讲的是取象配对，不是应事领域判定；M3-R-186「墓库看十神含义法」只讲墓库）。375 + 369 + 200 条中确无「先定引动对象→再定领域」的裁决程序条。
- 具象映射表：如上述，语义原料在库但形态不成立，不能反过来说「已被覆盖」。

### 可机检点

- **可机检**：被引动对象清单可自动生成——取 `relations.edges` 中 scope 含 `dayun`/`liunian`/`dayun+liunian` 且 members 含 natal 地址的边，其 natal 成员即被引动之星；再按 `chart.pillars[].ten_god` / `branch.main_ten_god` / `hidden[].g` 映射为十神领域标签。**这是本条最可机检的部分**（agent 侧已有现成数据，缺的是把「引动清单 → 十神领域」固化为裁决步骤）。
- **半机检**：「实质加力 vs 常态边」需 scope 过滤 + 力量比较，engine 有 scope 字段、无「是否新增加力」判定函数。
- **不可机检**：一星多领域时按命主所问之事择主领域，须 Agent 结合语境裁决；吉凶仍由各领域内规则决定，不属本条。
