## 3. 预注册口径

### 3.1 证据项定义

- **宫位**：`Y/M/D/H` + `.s/.b` 地址，精确匹配。域内取法：
  - 婚姻：日支 `D.b`（配偶宫）+ 配偶星宫位（乾取财星、坤取官杀；地支主气优先，其次透干；缺位则退看月令）
  - 事业：月支 `M.b`（事业宫）+ 日干 `D.s`（日主）+ 官杀宫位（主气优先，其次透干）
  - 健康：日支 `D.b`（身体宫）+ 日干 `D.s` + 月支 `M.b`（气候）
  - 财运：财星宫位（正财/偏财，主气优先，其次透干；缺位退看月令）+ 日支 `D.b`（主位/取财之身）
- **关系边**：取与该题首要宫位相关的本命地支边（`layer=branch, scope=natal`），最多 4 条；
  **已剔除该盘在 fixed-20 里被考的那一对端点**（防串答案）。匹配：`edge_id` 精确，或 `members 集合 + kind` 一致。
- **source_ref 区间**：
  - 婚姻：`婚姻专辑:L15-L17`（配偶宫为主/配偶星为辅）+ `L37-L44`（配偶宫与配偶星相关性的类型）
  - 事业：`23.盲派中级命理学:L2819-L2827`（官命核心/有根/主位）+ `L2829-L2831`（官命组合与部门象）
  - 健康：`疾病:L3-L11`（看疾病的方法）+ 日支字的象法行（`L13-L37` 内对应单行，如 午→L27）
  - 财运：`求财:L3-L5`（食伤/财临门户求财）+ `命格组合:L3-L7`（财生官杀/官统财原理）

### 3.2 召回与判定

| 指标 | 定义 |
|---|---|
| per_question_recall | 命中项数 / 该题预注册项数（三类等权，每项 1） |
| **macro_recall（主判定）** | 全部题 `per_question_recall` 的算术平均 |
| micro_recall（副） | 全部命中项数 / 全部预注册项数 |
| domain_macro_recall | 按域分组 macro（诊断用，不改总判定） |

| 阈值 | 判定 |
|---|---|
| macro_recall ≥ **0.80** | PASS |
| macro_recall < **0.60** | KILL |
| **0.60 ≤ macro_recall < 0.80** | GRAY（可重测一次，仍灰记灰；不得改阈值/删题） |
