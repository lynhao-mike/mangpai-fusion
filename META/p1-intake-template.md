# P1 真实案例录入模板（截止 2026-10-30）

> 只收 **2026-10-30 之前已发生**的事实；未来事件不进 P1（P2 另做前瞻）。
> 每个案例必须同时有「锚点事实」和「留出事实」；锚点事实不得用于评分。

## 案例字段

```json
{
  "case_id": "R01",
  "birth": "1985-03-12 08:30 或 四柱",
  "pillars": "乙丑 己卯 庚申 庚辰",
  "gender": "乾",
  "birthplace": "可选",
  "question": "命主真实想问的一个问题",
  "domain": "marriage|career|health|wealth|other",
  "known_facts": [
    {"date": "2019-06", "fact": "已发生的事实，一句话", "source": "命主/知情人/文档"}
  ],
  "holdout_facts": [
    {"date": "2021-11", "fact": "未用于锚定的已发生事实", "source": "同上"}
  ],
  "consent": "匿名/授权使用",
  "cutoff": "2026-10-30"
}
```

## 规则

- `known_facts` 1–3 条，用于生成 1–2 个锚点是非题；`holdout_facts` 1–2 条，P1 评分用；
- 所有日期 ≤ **2026-10-30**；不写未来、不写预测、不写“应该”；
- 锚点事实和留出事实不能是同一条；
- 没有事实的案例可以收，但只能进 P0/演示，不进 P1 评分；
- 匿名化：姓名/联系方式删掉，保留性别/出生信息/事实。

## 提交方式

把 3–5 个案例按上面 JSON 贴给我即可；我先做 **P1 试跑**（3–5 例），再扩到 10–20 例。
