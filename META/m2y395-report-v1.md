## 2. 触发器与方向规则

预注册原文见 `tasks/T-151/PROMPT.md` §1.2–§1.4；实现逐字对应：

- **触发器**：原局存在 `kind == "chong"` 的边且成员含日支地址 `D.b`。只看 `scope == "natal"`，
  不含大运/流年，不含 `stem_chong`（天干冲），不含刑/穿/合。
  冲边由 `engine/facts/relation_graph.py:210-222` 建（`_CHONG` 六冲表见同文件 `:53`，
  含辰戌、丑未），地址序 `_NATAL_ORDER` 见 `:45`。
- **方向**：对每条冲边的另一支 `other`，比较**本气五行**：
  - `KE_MAP[wx(D.b)] == wx(other)` → `self_controls`
  - `KE_MAP[wx(other)] == wx(D.b)` → `other_controls`
  - 其余（含辰戌、丑未等同五行）→ `no_ke`
  - 五行克序 `KE_MAP` 见 `engine/predicates/types.py:60-62`；支五行 `ZHI_TO_WUXING` 见 `:73-79`。
    五行相克是 5-循环，两个条件不可能同时成立（实现按上序判定）。
- **预测映射**：`self_controls → ["B"]`，`other_controls → ["C","E"]`，`no_ke`/`ambiguous → []`（弃权）。
- **多冲**：7 期有多条 `D.b` 冲边（§3.2 表），因六冲一对一，同期的多条边必指向同一支/同一五行，
  实测 `ambiguous = 0`。

## 5. 边界与风险（不许当作「已解决」）

### 5.1 11 期走了 clock_beijing 回退（唯一口径敏感点）

这 11 期的 `line3_true_solar` 写成「真太阳时: **阳历**1985年10月5日3时53分,农历…」，
多了一个「阳历」前缀，`RE_TRUE_SOLAR`（`tools/tiekoulu_eval.py:54`）不匹配，`parse_birth`
按 ADR-005 回退到 `line1_solar` 的钟表时。**本卡沿用该回退，不改解析逻辑**（改了就改了口径）。

逐期实测（一次性诊断，未写进产物）：把 `阳历` 前缀补进正则后用 line3 重新建盘，
11 期中 **10 期冲边结果不变**，只有 **第1292期** 变化：

- 回退钟表时 `1979-09-19 20:10` → 日支 **丑**，与未支相冲 → `no_ke`
- 用 line3 真太阳时 `1979-09-20 19:19` → 日支 **寅**，原局无冲边

即：若换成 line3 口径，总例数 78 → 77、`no_ke` 19 → 18，**scored 59 与 22/59 不变**
（第1292期在弃权支）。另 2 期落在 78 内但两支口径同结果：第1290期（`other_controls`）、
第1226期（`self_controls`）。

**结论**：§1.5 只在「`parse_birth`（含回退）口径」下复现。这不是实现错误——回退是
`tools/tiekoulu_eval.py` 的既定行为，卡面要求复用该路径。

### 5.2 晚子时 / 跨日

- 晚子时（hour == 23）**5 期**：第1497、1477、1468、1458、1370期。引擎会带
  `boundary_warnings` 与 `variants`；本卡按默认 `zi_shi` 口径建盘，未做双口径并列。
- 真太阳时跨日 **2 期**：第1497、1370期（line3 与 line1 不在同一天）。
- 这 5 期都是 23 时出生，日柱随 `zi_shi` 口径可能变化；本卡没有换口径重算，
  因此这 5 期若进了 78 例，其分支只在默认口径下成立。

### 5.3 248 期缺性别 → 占位「乾」

建盘要 gender 只因为 `chart_from_solar` 要用它排大运（`engine/facts/chart_facts.py:476-488`）；
本卡只取 `scope=natal` 的关系边，边集与性别无关。实测：284 期分别以「乾」「坤」建盘，
`relations.edges` 的 `(id, kind, members, chars)` 序列 **284/284 完全相同**。
78 例中 19 例有题库性别（`gender_basis=bank`），59 例用占位（`placeholder`）。

### 5.4 冲边定义只覆盖 §1.2 写的那一种

本卡**不含**：`stem_chong`（天干冲）、大运/流年层冲、刑冲合穿的交互（合解冲、贪合忘冲）、
以及「冲了但被合住」的优先级消解。`relation_graph` 明确不做这类消解
（`engine/facts/relation_graph.py:1-8` 的模块声明）。若后续尺子把「夫妻宫被穿」也算进来，
数字会变，本卡的 78 不能直接复用。

### 5.5 题库文件名与实际范围不符

文件名 `tiekoulu_1507_to_1428.json` 暗示 80 期，实际是 **284 期（第1224–1507期）**。
本卡以卡面「284 期、2392 题」为准，未按文件名截断。这条只影响读者预期，不影响计数。
