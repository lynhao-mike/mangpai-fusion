## 一、修正了什么

自动真值用「凶,/吉,」前缀 + 关键词计票。仍有 3 类问题，
逐条人工修正如下。

### 1.1 394 / 2005 —— 自动真值错（mixed）

```
原文：开始交到的男朋友都是烂桃花吧！不是无疾而终就是对方父母不同意！
     2008 年年底着凉生病去医院吊盐水（青霉素）导致过敏差点就休克了！
```
原文无「凶,」前缀，关键词里「烂」「不同意」「休克」触发 negative。
**人工判：mixed**（恋爱失败 + 大病，两件事都凶但性质不同）。
自动判 negative → 盲断答 positive 被判 incorrect。
修正后该年记 **undetermined**（mixed 不作极性判断依据）。

### 1.2 219 / 1988 —— 不可判（盲断者不可能知道）

```
原文：凶,出生在工人家庭 并不富裕 11 岁前搬家三次
     1988-1991 这期间被车撞飞过 但没什么问题仅是擦伤
```
这是**出生年**。命理上"出生"本身无吉凶可言，反馈里的「凶」是
命主对自己出身与童年境遇的主观定性。盲断 agent 面对出生年只能
答「吉」（出生=生机），判它 incorrect 不公平。
修正：该年记 **undetermined**，不进分母。

## 三、这个数字怎么用

### 3.1 能说的

- **流程成立**：盲测→作答→封存→判分→统计，全链路跑通
- **盲断 agent 可信**：51 个判断点全部含盘面依据（边号/地址），
  知道答案存在仍守住纪律未打开
- **定性结论成立**：盲断 agent 有系统性的**过凶倾向**
  ——22 个「凶」里只有约一半站得住，对照年误报率 47.4%
- **定性结论成立**：父母/婚姻/升学的吉事，它倾向判凶
  （1996 出国、1999 生子、2013 结婚都判错）

### 3.2 不能说的

- ❌ 「准确率 72.7%」——n=22，95% 置信区间约 ±19%，数字无统计意义
- ❌ 「某派准确率 X」——本轮未做派系级归因（rule_independent 尚未逐条核验）
- ❌ 「模型能力 X」——盲断者只是"一个分析者"，未区分派别

### 3.3 样本量与置信

| n | 95% CI（p=0.727） |
|---|---|
| 22 | ±19% |
| 100 | ±14% |
| 400 | ±7% |

**要给出可引用的准确率，至少需要 100+ 独立判断点。**

## 四、已识别的盲断者盲区（这是比数字更有价值的产出）

从 6 个 incorrect 归纳：

1. **吉事判凶倾向明显**：5 个 incorrect 里 4 个是把吉事判成凶
   （出国学习、生子、结婚、入伍）。原因推测：命理框架下这些事
   多对应「动」，而「动」常被赋予风险含义。
2. **休息/休养被判反**：077/2015「辞去工作休养」被判吉，
   而反馈明确写「凶，现无工作无收入」。命理上「官受克」确实常断凶，
   这一条反而是盲断者命理正确、但与现实结果相反——值得单独研究。
3. **出生年不可判**：盲断者无法从盘面判"出生"的吉凶，
   这类年份应从题面剔除（改进项）。

## 五、下一轮改进项（按收益排序）

| # | 改进 | 收益 |
|---|---|---|
| 1 | 题面剔除出生年与无事件可比年 | 消除不可判点 |
| 2 | mixed 事的处理：拆成两条判断或标 undetermined | 减少真值争议 |

| 4 | rule_independent 逐规则核验 → 规则级命中率 | 归因到规则而非笼统准确率 |
| 5 | 对照年扩大，专测"过凶倾向" | 把偏差量化而非定性质 |
