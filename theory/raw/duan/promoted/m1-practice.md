### 20.13.2 一对多传播：保留具体目标

原始讲义明确记载“大运一神冲两神，一般为冲动”；另一个流年案例写“一午冲两子”，并分别把年、时两处子水解释为长上之丧与本人血光之灾。
这支持同一岁运符号可指向多个具体目标；不据此推出每次多目标作用都必然对应多个独立现实事件：

```text
incoming_symbol
  → target_occurrence_1
  → target_occurrence_2
```

不能按地支字符合并目标。至少保留：

```text
occurrence_id / origin / pillar / branch / hidden_stem / role / relation / effect
```

证据：大运一神冲两神见 `sources/duan/MinerU_markdown_21.大连段建业-面授讲义（合集）134页_2056045222002622464.md:1162`；一午冲两子及两处子各自取象见 `sources/duan/MinerU_markdown_26..段建业《命理真诀导读风火集》_2056044863754526720.md:3419,3437`。D-21 `:3698` 讲的是“两冲一”的夹冲，不作为一对多证据。

证据等级：`SOURCE_DIRECT`（面授讲义）；
“occurrence_id”及字段结构是 `ENGINEERING_DERIVATION`。

### 20.13.3 同一来源对不同目标不得套用同一效果

壬子运、壬午年案例中，同一午字分别作用于原局子与大运子：原局子被冲动而触发财事，大运子被冲走，对应合资项目离开。原文按两个不同来源层的子分别解释，不支持把同字目标合并：

```text
午 → 原局子：冲动，触发财事
午 → 大运子：冲去，合资项目离开，大运财不起作用
```

所以作用效果取决于目标的来源层、当运状态、远近强弱和原局功能，不能由
`incoming_symbol == target_symbol` 直接决定。

### 20.13.4 多源共同作用：先记录事件，再裁决功能

戊申运、戊寅年案例中，原文同时描述：戊到位、寅申冲引动申、申卯合动卯，最终发财。
该案例称戊申运中戊癸合、申卯合，戊寅年寅申冲引动申并合动卯，随后记当年获利。它支持多项作用共同出现在一个结果案例中，但没有规定唯一“主触发器”，也没有独立拆分每一作用的因果贡献。

建议分析顺序：

```text
1. 记录每个岁运来源及其直接作用
2. 分别绑定到具体目标 occurrence
3. 判断每条路径是激活、保护、破坏、冲去、合留或仅显象
4. 检查这些路径是否汇入同一条原局做功链
5. 只有确认进入同一做功链后，才按原文标主要功神 / 辅助功神；“主事”仅作单独的研究者事件标签，带象 / 借象和岁运引动另轴记录
```

本案直接支持的范围是：戊申运中申尚未起作用，戊寅年寅申冲引动申并合动卯，随后当年得财。它可作该案中运年协同的例证，不足以推出“大运必建背景、流年必负责兑现”的普遍分工。
“主触发器必须后置裁决”属于 `ENGINEERING_DERIVATION`，不是段氏固定术语。

证据：`sources/duan/MinerU_markdown_21.大连段建业-面授讲义（合集）134页_2056045222002622464.md:2414` 与 `sources/duan/MinerU_markdown_19.《盲派高级班面授班笔记》卜文(段建业)_2056045264046317568.md:871` 记载相同盘例的相近说法；在未核明文本独立性前不按两个独立案例计数。

#### 作用次序、运期分段与因果主次不可混为一项

《命理瑰宝》分别给出三个不同层面的说法：

| 问题 | 原文依据 | 可支持的结论 | 不可外推为 |
|---|---|---|---|
| 岁运作用检查顺序 | 单个流年先与大运作用，再与原局作用（D-32 `:2448`） | 文本明示的关系检查次序，`SOURCE_DIRECT` | 先检查者就是事件唯一主因，或大运只能经由流年作用原局 |
| 通常职责 | 流年主要看应期、大运主要看吉凶；同时明说大运有时表示应期、流年有时表示吉凶（D-32 `:2452`） | 常见分工及其例外，`SOURCE_DIRECT` | 运年职责互斥或流年只报日期 |
| 大运字如何起作用 | 流年合大运可使大运字起作用；天干运期逢冲为提前引动，地支运期逢冲为冲走、暂离，且不必然为凶（D-19 `:687-691,841`；见 M1-D-177） | 关系对象与作用效果的局部裁决，`SOURCE_DIRECT` | 由某运字被引动 / 冲走即可选出事件唯一主因 |

### 20.13.5 做功角色、象法关系与岁运时序分轴

原文材料至少涉及三种不同问题，不应排成“主事 > 辅助 > 带象 > 仅引动”的单一等级：
做功角色说明某字在特定做功关系中的位置；带象 / 借象说明象义如何承载或互通；
引动 / 到位 / 应期说明岁运中的时间关系。一个字可以同时有象法关系、参与做功并在某年被引动，
这些标记彼此可并存，不能互相替代。

| 维度 | 可用标记 | 原文依据与分析边界 |
|---|---|---|
| 做功角色 | 主要功神、辅助功神、废神 | D-22 `:422` 明举巳制申时，卯生巳为辅助功神、巳为主要功神；D-10 `:1312-1324` 将功神放在做功关系中定义。另在职位案例中说“主神在主位为正职、在宾位为副职”（D-22 `:1032`），这是主神与宫位的案例性判断，不足以证明“主神”与“主要功神”是跨语境同义词。角色须绑定原句语境及具体关系，不自动等同某年事件的唯一主因。 |
| 个案事件角色 | `主事` | 研究者工作标签（`ENGINEERING_DERIVATION`），表示在已核实的具体事项中直接进入相关做功链；不是原文固定术语，也不等于“主位”或“主要功神”的无条件同义词。 |
| 带象 | `带象` | M1-D-076：干生支而支带干象。原文要求用于职业判断时核对象类及其与主位的关系（D-22 `:1016,1032,1060`）；象义本身不是做功证据。带象可与另有证据的做功角色并存。 |
| 借象 | `借象` | 修正后的 M1-D-077：原文列天干与禄神、同五行异阴阳两类互通象义关系（D-23 `:1901-1905`；同文见 D-02 对应章节）。不等同“主位借宾位”或“反客为主”，也不自动证明做功或所有权。 |
| 岁运时序 | 引动、到位、出现、应期；`仅引动` | 前四者有原文用语及案例；`仅引动`是研究者暂记标签（`ENGINEERING_DERIVATION`），只表示目前证据止于岁运触发、尚未证成其进入具体做功链。它不表示事件轻微或永远不能参与做功；补得关系证据后应更新标记。 |

“辅助”必须注明是在说原文的“辅助功神”，还是只说象义上的辅助说明；M1-D-076 旧摘要中的“与主位无关系时仅作辅助”容易把二者混为一谈，现已收窄为：无主位关系时，不据带象单独推出职业归属 / 财官权力归己，不等于另有一个辅助功神参与做功。

### 20.13.6 使用红线

1. 不把同类支或同类藏干压缩为一个目标。
2. 不把一次冲合自动判为主事。
3. 不把多个控制路径相加成单一力量分数。
4. 不把“出现 / 引动 / 合动”直接等同于吉凶结果。
5. 不因出现带象或岁运引动就推定进入做功；若另有关系与案例证据，可同时记录其象法、做功及时间角色。
6. 没有足够证据时，输出 `OPEN QUESTION`，不强行选择主触发器。

#### 藏干模型核验（交接项 6）

D-35 §“地支遁藏”按四长生、四帝旺、四墓库分别说明支中本气与所含之气，并列出具体藏干；
同书要求把各支藏干逐一标出十神。这里支持“按宿支 occurrence 保存藏干及其十神身份”，
但不支持把所有藏干压成单一五行计数，也没有建立一套适用于所有地支的统一数值权重。
原文用“本气、含气、所墓之气、余气”等名称描述不同支内成分；M1 的结构字段应保存来源
使用的原词，不要默认每支都可无损套入统一的“本/中/余”三档。

D-35 §“五行余气”称余气为退气、“气虽有但无力”，并说墓中余气透干引出或冲墓后方有用；
这是余气在该段得气语境下的定性说明，不是藏干之间可直接量化的固定换算表。D-02 的乙酉
应期例另说候选对应“先代表地支，再代表天干”，支中按卯本气、未墓气、辰余气排列
（`sources/duan/MinerU_markdown_23.盲派中级命理学_2056045463376420864.md:243-245`）。
这是该应期问题的代表顺序证据，不能改写为跨命局的藏干强弱公式或自动激活规则。

截至本次对仓库 `sources/duan/` 的固定百分比及本/中/余比例检索，未发现段氏给出
60/30/10 等藏干数值配比。因此这类比例不得标为 `SOURCE_DIRECT`；这是当前语料中的
“未检出”，不是段氏明文禁止研究者建立并另行验证任何数值模型。

交接稿的 `HiddenStem` 字段清单属于工程数据模型，不是段氏原有分类。宿支、藏干、原文层级
名称、十神身份可作为可追溯的观察字段；根、党、作用、做功角色须分别依据对应结构和案例
判断。`reality: REAL/VIRTUAL`、`vitality`、`activation`、`control_state`、`temporal_state`
等状态名目前应标 `ENGINEERING_DERIVATION`，不能仅因字段适合软件存储就当作原文理论。

#### 透干代理范围核验（交接项 10）

代理既不能弱化成“只能取象”，也不能扩大成整支关系图的自动复制。现有原文证据可分层记载：

| 层次 | 回源结论 | 证据等级与边界 |
|---|---|---|
| 条件性宿支功能代理 | D-02 明说：原局支中所藏之字在运年天干出现时，该干可代表宿支信息，“其作用就相当于”宿支（`:513-515`） | `SOURCE_DIRECT`；原文不只支持取象或信息提示，也支持在“同一藏干确在原局宿支中、且于运年天干出现”条件下承接宿支作用；但没有说明“相当”是否意味着逐边全量复制 |
| 案例中的功能与具体关系回接 | 蒋介石例以甲代表亥中甲，甲透后合身、不能制住对手，回接亥所代表的官星 / 对手功能；甲申离婚例以甲代表亥妻财；乙代表未的食品生意例将得财归到未中食神（D-02 `:517-553`；D-35 `:1801-1824`） | `CASE_SUPPORTED`；支持透干代理参与具体功能链，不同命例中的解释不等于一案多次独立验证；食品例在 D-02、D-27、D-35 及 2010 面授笔记重复，按一案计 |
| 运干代理进入具体做功关系 | 坤造壬壬甲乙、辰寅辰丑，己亥运时原文称“己能代表丑”，甲己合有功；同段把寅亥合判为无功（杭州教材 `:2518`；重庆教材 `:2123`） | `SOURCE_DIRECT` 的案例表述 + `CASE_SUPPORTED`；显示所藏同字成为运干后可被用于一条具体有功关系，同时逐条排除另一无功关系；两处为相近重复文本，不按独立案例累加，也不推出干作用普遍优先于支作用 |
| 透出干受关系后的宿支状态回接 | 乙代表辰而被辛克，原文说“等于坏了辰”；另一坤造乙到未后被辛冲、坏乙，原文说“等于坏了未”（D-02 `:565-571`；D-35 `:1826-1830`；武当山讲义 `:397-405`） | `CASE_SUPPORTED`；说明特定作用可回接宿支状态；乙辰案跨文本重复，不按独立案例累加；武当山例是另一讲义命例，仍非独立现实鉴真 |
| 代理不等于不经裁决的关系边复制 | 乙代表未的食品生意案例同时提到原局“子未穿”，但随后明确判断乙“不受伤”，并按乙受壬生、再生日主解释得财（D-02 `:541`；相近文本见 D-35、2010 面授笔记） | `CASE_SUPPORTED`；不能把支层既有关系自动判成透干代理必受同样影响；须逐案判断作用对象、强弱及透出干自己的关系链 |
| 宿支全部关系图是否自动复制 | 原文的“作用就相当于宿支”给出了较强的功能等同表述，但现有例证只展示特定功能或具体作用链；未找到原文明列宿支全部藏干、所有关系对象和全部做功路径均无条件转移 | `OPEN QUESTION`；不得缩窄成“只能取象”，也不得扩大成已经证实的全关系图自动复制 |

D-02 同一语料另记“亥不代表申，因相穿了，是两家”（`:237-239`）。这是支与支之间代表关系受具体结构限制的例子，
不是遁藏透干规则的直接反例；它只能作为反对无条件合并不同支 / 不同关系对象的边界旁证。故本节将“宿支功能可以由透干承接”列为直接文本命题，
将“具体哪些关系随之生效”限于案例证据，并把“宿支整张关系图全量复制”继续列为未决边界。

候选对应也不总能预设为单一排他选择。D-02 对乙酉年例列出卯、未、辰三个地支候选并给出先后顺序（`:243-245`）。
言明2011例30同一命盘在乙丑1985年记“乙到卯到”，乙酉2005年又记“乙到未到卯象，卯酉冲制杀”
（`sources/duan/MinerU_markdown_段建业言明2011干支象法职业实战光盘讲座笔记_2056046186927423488.md:851-861`）。
这使“乙同时关联未中藏干与卯禄象”成为有案例依据的候选解释，但讲义速记没有说明 2005 年两条对应是否同时激活、先后如何裁决；
它不能推翻 D-02 当例给出的顺序，也不足以建立通用多目标算法。D-27 另分乙代表禄时虚透弱化、乙代表未时只作应期
（`sources/duan/MinerU_markdown_应期_2056043432704139264.md:154-156`），说明对应对象变化会改变该字的解释，不能混用虚实语义。

现有材料没有把代理范围划成 `NONE / STEM_ONLY / BRANCH_SYMBOLIC / FUNCTIONAL_ROLE` 等固定等级，
也没有规定“只有宿支先是核心功神 / 贼神 / 捕神才可传递功能”的统一门槛。故 `proxy_scope` 若作为实现字段，
只能标 `ENGINEERING_DERIVATION`，并应逐案记录代理对象、原局功能、透干实际受作用方式和结果回接依据；
不得把工程枚举写成段建业原始分类。

根、通根并非在当前语料中只有一个统一的柱位定义。初级讲义问答针对“其他柱上的地支是否也算通根”回答
“坐下通根才算通根”；但同一讲义随后说甲乙共根、甲见卯为根、乙见寅为根（`:1112`），并在乙庚辛壬 / 巳辰卯辰例中
明称乙有“辰、卯之根”（`:1384`）。面授资料还用“甲木通根寅木”等案例表述（D-21 `:4461`）。
此外，《盲派命理开山之作》说五行坐墓地、坐余气均可“通根得气”，同时分别说明墓气、余气性质
（D-35 `:690-696`）。这些材料应并列保留：窄口径问答不能抹掉案例中的跨柱“根”，跨柱案例也不能反过来
抹掉该问答的坐下限定。分析时注明所依据的原文用法；`REMOTE_SUPPORT` 可作为工程性位置标签，但不能替代原文实际使用的“根”字。

禄与原身则是方向相反的干支延伸关系，不等于根或通根。禄表天干入支行使权力；原身表地支在天干做事。
多份材料明确说辰戌丑未没有固定天干原身，禁止程序将辰戌恒映射为戊、丑未恒映射为己。
但这不等于四库与天干永无关系：资料另列丙戊同禄、丁己同禄，以及若干墓库半禄组合；《风火集》在
一个未土妻宫案例中明确说“未之本气可看作原身”。这些只能作为来源限定的关系或个案借象，不能反推
四库拥有普遍固定原身。面授讲义同一段还举甲辰“不需要”刑冲、戊戌强根不宜被冲坏等情况，故
“四墓无原身，所以凡墓库都必须刑冲才有用”不是可接受的通则；库的作用仍依所墓之物、根、用途及具体关系判断。
原始位置：D-22 `:1114`、D-35 `:1361`（无固定原身）；D-21 `:695,1953-1955`（半禄清单及刑冲例外）；
D-26 `:1567`（未之本气在具体案例作原身）。

原文另列丙戊同禄、丁己同禄、丁未/癸丑半禄等特殊互通，故也不能压成一张简单的一对一“干支相等”表。
工程上应把 `ROOT/ROOT_QI`、`LU`、`ORIGINAL_BODY`、`HALF_LU` 保持为不同关系类型；
`SEATED_LU` 若作为字段，应拆成位置与禄关系，不能与根状态并列混成同一枚举。

墓库方面，原始资料明确支持“四墓神没有固定原身”以及库被冲、刑、制干净的案例。
四组闭气对应“子丑闭丑中金、辰酉闭辰中水、午未闭未中木、卯戌闭戌中火”在初级讲义与面授笔记均有明文
（`sources/duan/MinerU_markdown_35.盲派命理开山之作_2056045397672648704.md:786-792`；
`sources/duan/MinerU_markdown_22.盲派初级命理学_2056045493286002688.md:1454-1462`；
`sources/duan/MinerU_markdown_19.《盲派高级班面授班笔记》卜文(段建业)_2056045264046317568.md:607-653`），
故四组对应本身可标 `SOURCE_DIRECT`。原文还说闭气后不能流行、不能引拔，只有逢冲才可用；
但这不等于已经证明闭气是永久状态、可被任意岁运无条件重开，或等同于软件中的完整 `ACTIVE/SEALED` 状态机。

原文对藏干受作用有两类不能互相抹除的表述：六合条目分别区分闭气与合伤，并点出辰中乙、寅中丙等对象；
另在丑戌未三刑全见的特定结构中说“支中藏干都刑坏了”（`sources/duan/MinerU_markdown_22.盲派初级命理学_2056045493286002688.md:1454-1462,1986`）。
所以正确边界不是“支一受作用，藏干必全伤”，也不是“只要没点名，就绝无连带受伤”，而是保留该关系的明确对象、结构条件和原文效果。

### 20.14.2 第二阶段：党势、做功、制净、贼捕、反局

原始“宾主作用”材料给出一条清晰但非数量化的链条：势要与主一致，势还必须有大功；
功神是作用关系中的两个或多个神，核心功神之外可有辅助功神，不参与做功者为废神。
三合可称“结党”，三会有“统治、占据一方之气”的描述；这支持党势的结构性含义，
不支持把党势简化成五行数量或力量总分。

| 议题 | 案例/原文可证明的结论 | 当前等级 |
|---|---|---|

| 制法分类 | M1-D-021..024 延续“合制、冲/刑制、克制、穿制”四类说法；一般作用方式和结构方式是不同分类层，不代表见到关系就完成制 | `SOURCE_DIRECT`，具体效果须看结构/案例 |

“制净、制尽、制干净”目前只能作为原文的定性用词记录，不能擅自解释成有固定先后级差的状态枚举。
初级讲义明确说特定夹制及夹冲不尽（`sources/duan/MinerU_markdown_22.盲派初级命理学_2056045493286002688.md:458,464,2640`；另见
`sources/duan/MinerU_markdown_23.盲派中级命理学_2056045463376420864.md:219,2015,2921`）。
但面授讲义李鹏例又称“辰上有戊，夹住制，制干净了”，并另记地支控制与癸巳天地合各自制净
（`sources/duan/MinerU_markdown_21.大连段建业-面授讲义（合集）134页_2056045222002622464.md:1206`）。
这不是可以靠择一条原文消掉的差异：夹制与远制保留为常见不尽的风险提示；具体完成度要以目标 occurrence、
究竟是哪一条路径、是否有其他关系介入及原文对结果的说明来裁决。

证据边界：旧提炼 `theory/raw/duan/d02-theory.md` 写有“夹制远制制不尽，留余烟”，但在当前 `sources/duan/` 原始转录中未检出这句或“远制不尽”的同义原文。因此夹制不尽有直接材料支持；把远距离控制一概判不尽、以及“留余烟”作为段氏原话，暂列 `SOURCE_SECONDARY` / `UNVERIFIED_HYPOTHESIS`，待找到可定位原始段落后再升格。

同一初级讲义的材料还给出三条重要边界：癸火例称“制干净”但同时说能量小、效率不高
（`:554`）；和珅例分别说年上午“没有制净”、时上午“制净了”（`:2600`）；对未亥午子例则答“这个不算制尽”，理由是“做功是双向的”（`:2830-2832`）。
因此，完整性不能由关系次数、几何上的夹住或单一方向的控制自动推定；也不能把“制净”直接换算成事件一定吉、财官一定高。

段氏资料确有对特定关系的效率比较，不能据此说“原文没有任何排序”；准确边界是：保留来源中的
局部比较和前提，不合并成脱离结构的统一等级。“围克”在克制内部被评价为高效，也不能直接推出
任一围克都制尽。“某一冲合自动完成制净”同样没有普遍依据。D-28 过河拆桥案例里的不同做功方式
及财富级别差异，只能留在该结构和已列案例范围内，不得迁移成普遍制法排序。穿制和合穿的分歧见下列原文对照。
附件中的 `ControlPaths`、`effective_coverage`、`residual_power`、`PartyGraph`、`WorkGraph`
可以作为内部记录模型，但统一标为 `ENGINEERING_DERIVATION`，不得伪装为段氏原话。

这里要把两种原文分类分开：一般关系层列“刑、冲、克、穿、合、墓”（D-10 `:1316`），
六类结构层则是制用、化用、生泄用、合用、墓用、复合（见
`theory/raw/duan/d10-theory.md` §2.2）。初级讲义另明确说“破不是做功方式，破不能做功”
（`sources/duan/MinerU_markdown_22.盲派初级命理学_2056045493286002688.md:608`），
因此“破”不能作为这份一般做功关系清单的成员。两层清单都不意味着凡出现某种关系便必有有效功；
段氏另将耗能而无效率、或不耗能不做功者列作废神（D-10 `:1322-1324`），并以是否与主相关、
是否形成效率区分做功与无功（`sources/duan/MinerU_markdown_宾主作用_2056044174571667456.md:231-248`）。

制法细则中，初级讲义称四组（酉戌、卯辰、子未、丑午）在一方力量足够时可作穿制，
并称寅巳、申亥属穿中带生、不能制（`sources/duan/MinerU_markdown_22.盲派初级命理学_2056045493286002688.md:1860,2980`）。
但《大连段建业面授讲义》同一合集中，一处说“穿制不了对方，唯有穿制不了”
（`sources/duan/MinerU_markdown_21.大连段建业-面授讲义（合集）134页_2056045222002622464.md:2425`），
另一处又说四组力量大、必须旺则“穿也为制”（`:3717`），并以“穿制”讨论宾主方向（`:3949`）。
故该原始转录内部存在不能消解的明文冲突。分析时先记录穿及其损害/不和/穿倒作用；只有当具体
结构、强弱方向和案例支持时，才把“穿制”作为功能解释，且须注明此处采用的是哪一条原文口径。
不得仅因出现穿就判控制完成，更不得把“穿”自动视为必然不能控制。此为保留证据冲突的审慎口径，
不是对段氏不同讲义作虚假的统一。

合穿问题同样不能用单一优先级裁决。《命理珍宝》一例说卯戌合与卯辰穿须“合穿兼论”，并交代
庚辰年辰戌冲使卯戌合的条件改变后，卯辰穿才得以集中作用（`sources/duan/MinerU_markdown_30..命理珍宝_2056044626612772864.md:309`）。
中级讲义另有癸未年冲丑、合午而“解了丑午之穿”的具体事件案例
（`sources/duan/MinerU_markdown_23.盲派中级命理学_2056045463376420864.md:687`）。
二者说明合、冲和穿可在特定结构中改变彼此的实际效应；不支持“合一概不能解穿”，也不支持“有合便自动解穿”。

### 20.14.3 第三阶段：原局—大运—流年及功能裁决

关于三层分工，段氏资料同时保留“原局定富贵贫贱，大运流年看应期”“大运表吉凶、流年表应期”的概括，
以及流年有时也表示吉凶、大运有时也表示应期的明确限定。这里须区分两种不同的“顺序”，二者并不矛盾：

| 顺序类型 | 原文 / 研究流程 | 含义与边界 |
|---|---|---|
| 分析展开顺序 | 先识原局结构与先天垂象，再看大运阶段，最后核对流年；这是便于分析的 `ENGINEERING_DERIVATION` | 说明分析者先建立什么背景，不等于作用发生的时间先后，也不规定谁是事件主因 |
| 单个流年的关系检查顺序 | D-32 明说流年先与大运作用，然后才与八字作用（`:2448`），属 `SOURCE_DIRECT` | 这是该年岁运作用的检查次序，不表示大运只通过流年才作用原局，也不表示流年因先检查而拥有更高因果权重 |

大运与原局仍须按其自身关系直接判断；D-32 对大运与八字的冲合刑害另列局部作用说明（`:2458`）。
D-32 还称流年主要看应期、大运主要看吉凶，但同时限定大运有时也表示应期、流年有时也表示吉凶；
若某年没有具体事件应验，仍需看流年对原局的生克作用。故不可把“大运=吉凶、流年=时间”当成绝对职责边界，
也不可将上述次序扩写成统一因果排序或工程中的状态转移图，并称为段氏原句。

证据：2011 重庆面授班教材 `:127-151`；D-32《命理瑰宝》`sources/duan/MinerU_markdown_32.命理瑰宝_2056044575031222272.md:2444-2458`；
D-06/D-09 先天垂象与后天应期 `d06-d09-theory.md` 所引章节。证据等级：`SOURCE_DIRECT`；三步分析流程是 `ENGINEERING_DERIVATION`。

岁运到位及状态变化应分层记录：

| 可记录现象 | 原文支持 | 不应外推为 |
|---|---|---|
| 原局字在运年出现，称“出现应/字到了” | `SOURCE_DIRECT`：D-27 出现应，见 M1-D-228 | 出现即必然发生吉凶事件 |
| 禄、原身到位 | `SOURCE_DIRECT`：D-02 §第二章二、D-17 §一、D-18 §二，见 M1-D-058/176 | 任意藏干都等同禄或原身 |
| 原局藏字透到运年天干 | `SOURCE_DIRECT`：D-02 §第二章三，见 M1-D-059；代理范围见 §20.14.1 | 整个宿支及其全部关系自动复制到天干 |
| 运年冲合引动原局/大运之字，或墓气到位引动墓库 | `SOURCE_DIRECT`：D-21 `:1248,4509`、D-27 引动应，见 M1-D-229 | 引动必然进入核心做功或兑现结果 |
| 虚透、通根、闭气、做功受损等具体状态变化 | 原文有条件性描述和案例；闭气四组与“逢冲才可用”见 D-22 `:1460` | 一套覆盖所有字符、固定次序的通用现实状态机 |

`DIRECT_REPEAT`、`LU_ARRIVAL`、`ORIGINAL_BODY_ARRIVAL`、`HIDDEN_STEM_REVEAL` 是便于逐事件保存的工程事件类型；“存在→激活→现实兑现”等统一生命周期未见段氏原文定义。`VIRTUAL/REAL` 可用于忠实记录原文特定虚实判断，但不得视为自动互转的普遍状态。

现有讲义支持以下传播事实：一神可冲两神；一午冲两子案例分别解释年、时两处目标；两个冲也可共同参与对一个结构的作用。流年可提前引动大运或原局中原本只作体、象的支；这些是 `SOURCE_DIRECT` / `CASE_SUPPORTED`。然而“一对多/多对一图”“WorkGraph 路由”是 `ENGINEERING_DERIVATION`，不得把发生了多条关系直接等同于每个目标都进入做功。

主事、做功角色、象法关系和时间角色分别记录，不作为互斥四级裁决：

| 分轴 | 标签 | 裁决边界 |
|---|---|---|
| 做功关系 | 主要功神 / 辅助功神 / 废神 | 原文直接分类；须说明所参与的做功关系及目标。主要功神不自动等于某事件唯一主因，辅助功神也不表示象义上的普通补充。 |
| 案例事件 | `主事` | `ENGINEERING_DERIVATION`：研究者标签，须有具体事项与做功链的对应证据；不等于“主位”或“主要功神”的同义词。 |
| 象法 | 带象 / 借象 | 原文术语。带象依干生支及主位关联判断可否用于职业等推断；借象依禄神关系或同五行异阴阳互通象义。象法结论本身不自动建立做功或归属。 |
| 岁运时序 | 引动 / 到位 / 出现 / 应期；研究标签 `仅引动` | 前四项有原文用语；`仅引动`只表示当前证据尚未证明其进入具体做功链，不表示事件轻微或永久不能参与做功。新证据出现时可并列更新。 |

“流年永远辅助”“大运永远主事”“引动必兑现”都应判为错误泛化。“引动/到位/应期”有原文用法；本次检索未发现“兑现”作为统一的段氏技术分类，也未发现“破功”作为固定状态标签。可将“兑现”用作研究者对案例结果实现的描述，将“破功”用作原有做功受损的工程标签，但须回接具体原文事件；“反局”则是段氏直接术语，且包含多种层次，不能等同一般变弱。证据不足时保留 `OPEN QUESTION`，不强行指定唯一触发器。

| 冲制 / 刑制 | 库冲被称效率较高；冲得近为佳。其他冲须有强势；力量相当的一对一冲可只是对抗、动与消耗，强弱成势才可能冲伤、冲去 | D-21 `:1433,2852`；初级讲义另列冲库及成势条件，D-22 `:1768` 区分一冲二、二冲一与夹冲语境 | 不把“冲库高效”变成逢冲开库，也不把夹冲、冲动、冲去、冲破混成同一效果 |
| 克制 | 围克被称效率最高；天干克地支可有效，但须天干有势；邻克效率低。另有干制支较高、支制干较低的方向比较 | D-21 `:1435,2816,2825`；例中强调目标受组合围制，不只是关系条数 | 不以包围的几何形态或多条边自动判制尽；方向比较不能脱离具体干支与党势 |
| 穿制 | 初级讲义列酉戌、卯辰、子未、丑午可相制，且要求一方强；寅巳、申亥按该段为穿中带生、不能制。面授讲义另处有“穿不能制”及强势例外，故来源内部口径冲突仍在 | D-22 `:2980`；D-21 `:1271,1437,2425,3717,3949` | 不把“穿必能制”或“穿绝不能制”单独提升为全库定论；个案需保留所据口径、力量方向及实际结果 |

以上只构成机制内部的局部比较。原文关于“制、化、泄生”层次的概括属于另一比较轴；合穿并见亦有“兼论”及具体岁运改变效应的案例（§20.14.2）。二者都不能被拼进一张统一制法排名表。现有文本支持 `LOCAL_COMPARISON`，不支持 `GLOBAL_PRECEDENCE`。

### 制净 / 制尽：案例可检验条件，不是阈值

| 案例现象 | 可支持的结论 | 证据位置 |
|---|---|---|
| 夹制、夹冲在初级/中级讲义中常被说成不尽；另有面授案例说夹住后制干净 | “夹”是审查未尽的风险，不是必然未尽的定律 | D-22 `:458,2640`；D-21 `:1206`；D-23 `:219,2015,2921` |
| 和珅案例分别记年上午未制净、时上午制净 | 结论须落实到具体目标柱位 / occurrence，不能按同类字合并判定 | D-22 `:2600` |
| 未亥午子案例以“做功是双向的”否定制尽 | 需记目标是否仍参与反向作用；关系存在或单向控制不足以推出“尽” | D-22 `:2704-2706` |
| 戊辛丁癸、申酉未卯案分别称未制酉不尽、卯酉冲不净、卯申合不净 | 多条关系并列不等于控制路径可加总，也不等于目标整体被清除 | D-22 `:2722-2726` |
| 原文同称制干净而另评能量小、效率不高 | 完成度与效率 / 层次是不同判断维度 | D-22 `:554`；另见 D-21 `:2818` |

据此可把“逐个目标、逐条路径、是否双向做功、是否尚有原神 / 支持 / 保护及岁运改变”作为案例记录时的核查项；这是 `ENGINEERING_DERIVATION`，不是原文给出的充分必要条件或计分模型。现有语料没有稳定证明“净”与“尽”为两种有先后级差的术语，也没有为任意命局提供数值阈值。新增证据前，不据此改写规则库。

### 应期与吉凶分工：一般职责、例外与裁决边界

| 资料 / 案例 | 原文证据 | 可以支持 | 不能据此推出 |
|---|---|---|---|
| 一般职责 | D-32《命理瑰宝》`:2452`、D-33《命理珍宝讲义》`:810`：流年主要看应期、大运主要看吉凶；同时明说大运有时表示应期、流年有时表示吉凶 | 两者是常见分工而非互斥职责；D-32 还说无具体应事时仍要看流年对原局的生克结果 | 大运永远只判吉凶，流年永远只报年份 |
| 大运自身成为应期 | D-30《命理珍宝》`:468` 的某市长丙午运，以忌神得根并被制化解释该运升任；`:645-647` 的格林斯潘例以官星出现且受制解释掌权运。D-32 `:2442` 以丁丑运定父亡的大运窗口，再以甲戌年选具体年份 | 大运可标出事件发生的较宽运期，也可能成为某类做功 / 忌神制化实现的应期 | 每个事件都必须由大运先定性，或大运必是唯一主因 |
| 流年影响当年吉凶 | D-32 `:2466`：己酉运原本不佳，庚辰年因辰酉合绊忌神酉财而发财；`:680` 的甲寅运案例还按己未、庚申等流年关系解释运程转折 | 流年通常细化应期；岁年对大运、原局的实际作用也可能改变该年的结果 | 将流年单独贴成用神年吉、忌神年凶，或把年作用脱离大运和原局单断 |
| “只管应期”措辞 | D-27《应期》`:15-17`、广州讲义`:54`、2010 面授笔记`:1367` 有“流年只管应期，不管吉凶；吉凶由原局与大运管”的概括，后文仍要求配合大运与原局定吉凶 | 保留为这些应期讲义中的职责简述；其操作边界要求回看原局和大运 | 用该简述覆盖 D-32 对岁年也可显示吉凶的明确例外。两类文本的措辞差异应留档，不擅称已证明其版本或教学层级关系 |
| 串宫旁路 | D-18 案例`:57` 说先由原局和大运生克制化确定事件运期，再以流年串宫定具体年份 | 该案例将串宫作为具体年份筛选信号，可与结构作用并列记录 | 将串宫取应期与岁运生克作用合成一个裁决算法，或据此升级为段氏统一法则 |

**审定结论。** 原文可以支持“原局先定事件信息，大运通常看阶段性吉凶并可形成运级应期，流年通常细化具体应期但也可通过实际作用影响当年吉凶”。“喜忌”属性与某年关系作用后的具体吉凶结果须分开：不能仅按用神 / 忌神标签断年，但不能因此否认原文所说的流年吉凶例外。D-32 与 D-33 的章节及案例有重合，D-30 / D-32 / D-34 亦存在重刊或修订文本；版本关系未独立鉴定，不按重复文字累加为独立证据。

**分析时的研究者检查法（`ENGINEERING_DERIVATION`，非新增段氏规则）：** 先注明问题要判断的是十年运期、具体流年还是更细时间；原局事件信息与大运运期分别立证；再依 M1-D-060 的关系检查次序核对流年对大运、原局的具体作用。分别记录“时间窗口 / 应期候选”与“该层关系造成的吉凶结果”，若证据只到大运而未能筛出流年，就停在运级；若没有足够资料决定年、运哪一层主导某结果，保留并行路径与 `OPEN QUESTION`，不强定唯一主触发器。

本项回源审查已完成；“年、运在具体案例中何时兼具应期与吉凶作用”已有局部例证，但跨命局的统一条件尚无原文算法，故不新增正式规则，也不把问题包装成已经完全解决的通则。
