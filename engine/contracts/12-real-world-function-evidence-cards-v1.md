## 2. 跨卡总则

### 2.1 现实功能本体

F01–F12 是现实功能本体，不是职位目录、行业目录、十神目录、格局目录或流派目录。十二项功能均可成为候选，但正式输出必须通过现实必要硬门。

允许一主一副或多功能独立并存；并存必须分别闭合证据链。证据缺失时必须弃权，禁止为了目录完整强行输出。

### 2.2 禁止直接跳转

不得由以下任一项目直接推定功能成立：

- 职业、职位、部门、机构、平台或场域；
- 学历、证照、资质或社会身份；
- 收入、资产、名气、粉丝、奖项或结果；
- 十神、格局、单字、单象或宽泛性格；
- 检索命中数、材料数量或同源案例复述。

理论候选不得证明现实职业、现实作品、状态/事件等级或结果等级；现实反馈也不得反向升级原局根源与理论覆盖。

### 2.3 单家原局完整链

原局完整链必须在同一理论家族或同一派、同一命局、同一作用链内闭合，禁止跨派、跨局、跨案例拼接残件。

最低充分参与集合为：

```text
一家单家原局完整链
+ 一套明确的大运阶段作用解释
+ 具体事件所需的一套明确流年触发解释
+ 一个现实功能硬门
+ 一个本家破坏条件或跨材料有效反证
```

其他材料只能在至少一家原局完整链成立后，补充结构质量、调候、现实桥接、大运阶段、流年触发、应期、反证或明确弃权。材料沉默不算反对，不得用多数投票代替裁决。

### 2.4 现实层与理论层分账

现实层至少检查：

```text
对象
→ 命主动作
→ 动作归属
→ 功能路径闭合
→ 状态与事件分账
→ 结果层级分账
→ 最强竞争解释
→ 有限现实落点
```

理论层至少检查：

```text
同派、同局、同链原局证据
→ 原局承载与作用方向
→ 根源等级
→ 岁运完成方式
→ 破坏条件、竞争解释与弃权门
```

现实层与理论层不得互相补门。

## 3. 统一字段与闭合链

每张完整功能卡应登记：

1. 功能 ID 与名称；
2. 冻结总定义；
3. 现实对象、动作与动作归属；
4. 现实必要硬门；
5. 状态卡与事件卡；
6. 结果层级及其边界；
7. 相邻功能与最强竞争解释；
8. 理论原局门与原始语料门；
9. 强根源、弱根源或无根源；
10. 岁运完成方式；
11. 一个中心落点、最多两个替代落点、弱命中、反证与排除项；
12. 四维覆盖评级；
13. T0/T1/T2 输出精度；
14. 防矛盾门；
15. 出处索引与恢复状态。

### 3.1 状态与事件

稳定职责或持续功能状态与具体事件必须分账。事件只有形成截止日仍有效的职责、资源、身份、成果或路径后果，才能更新状态。历史事件不得自动证明当前状态，事件复杂度不得自动等于人生影响度。

### 3.2 结果层级

卡片内部结果层级只描述该功能链在本次事实中的完成程度，不等于 [`11-outcome-taxonomy-v1.md`](11-outcome-taxonomy-v1.md) 的 `L0`–`L14` 社会结果轴。两套层级不得互相回填。

### 3.3 三级根源

| 根源 | 定义 | 延伸边界 |
|---|---|---|
| 强根源 | 原局已有明确领域、对象、作用方向与承载节点，岁运主要完成或强化 | 可支持较强持续候选，仍须现实核验 |
| 弱根源 | 领域或对象可定位，但作用方向或承载不完整，主要依靠岁运组织 | 通常只支持阶段或本运候选，跨运需复核 |
| 无根源 | 原局无法定位对应功能，只见岁运临时组合或宽泛类比 | 原则上只支持短期机会或波动 |

根源必须同时通过命盘结构证据门与可定位原始语料证据门。流派数量、现实履历、岁运完成或路径固化不得反向抬升根源。

### 3.4 五种岁运完成方式

| 枚举 | 含义 |
|---|---|
| `ACTIVATE_EXISTING` | 原局功能链已相对完整，岁运使其发动或显现 |
| `COMPLETE_LATENT` | 原局已有对象与方向，岁运补入缺失连接或承载 |
| `REPAIR_DEFECT` | 原局功能受阻，岁运解除障碍、补不足或去有余 |
| `TEMPORARY_SUBSTITUTE` | 岁运以相似对象临时代替部分功能，现实性质不等同 |
| `INVALID_COMPLETION` | 表面似乎补齐，但功能、承载或阶段门槛不成立 |

根源与完成方式必须分别判断。禁止 `NO_ROOT + ACTIVATE_EXISTING`；`NO_ROOT + COMPLETE_LATENT` 原则上降为临时拼接；任何根源配 `INVALID_COMPLETION` 均不得生成目标主事件。

### 3.5 有限现实落点

结果揭晓前必须冻结：

- 一个中心落点；
- 最多两个允许替代落点；
- 弱命中的边界；
- 明确反证；
- 明确排除项。

核验后不得新增落点并计作本次命中。未被词典覆盖、但满足同领域、同方向和明确现实约束的结果，只登记 `TAXONOMY_GAP`，不计本次命中、不回写冻结记录。

### 3.6 四维覆盖

覆盖评级必须独立登记：

1. 理论家族覆盖；
2. 现代传承覆盖；
3. 中粒度功能覆盖；
4. 具体职业落点覆盖。

四维不合并、不互补、不按流派数量投票。同源案例不抬级；现代盲派不同作者不抬升理论家族覆盖；职业细分类默认降级。四维不得回填现实门、理论门、根源、岁运、状态/事件、结果层级、证据等级或置信度。

### 3.7 T0/T1/T2 输出精度

- `T0`：仅输出功能关联候选，不宣称现实功能已建立；
- `T1`：输出已闭合的中粒度现实功能；
- `T2`：输出具体角色、职业、媒介、类型或细分类，必须有同派细分类限缩、独立现实动作证据并排除最强竞争解释。

默认最高为 `T1`；`T2` 受限登记，证据不足即降至 `T1`。T 层不得由四维覆盖、置信度、职业反馈、机构平台、名气收入或单一符号升级，也不得与其他账本互相回填。

## 4. F01–F12 功能卡

### 4.1 F01 专业判断与技术解决

- 恢复状态：完整恢复；原闭区间未明示 T0/T1/T2，输出精度保持缺失。
- 冻结总定义：命主以可学习、可复用的专业知识或技术方法，对既定领域内的具体问题进行诊断、核算、设计、审查、操作或解决，并对结果承担一定专业责任；关键是解决已有知识与方法框架内的问题，职业名称不得反向代替功能证据。
- 现实硬门与双卡：现实职责必须包含诊断、核算、设计、审查、调试、专业操作或同类可核验结果，并具有专业裁量与结果责任。状态中心为以专业判断、设计、核算、审查或技术解决为核心职责的稳定岗位或独立执业；事件中心为进入或转为独立承担核心专业问题解决职责。证书、职位改名、行业平台、聪明学历、单一十神或偶发帮忙均不补门。
- 结果与竞争：使用既有方法解决已知问题归 F01；新增理论、方法或产品原理并验证归 F02；按稳定流程低裁量重复执行归 F03；多人、资源、进度与交付协调归 F04；投资融资及资本波动归 F09；直接面对患者健康风险归 F11。相邻功能分别闭合，不以行业、职位或同一事实重复增权。
- 理论双门／根源：至少一个理论家族形成完整结构作用链，作用方向明确；至少一个家族提供技艺、技术或专业宽类锚点，或现实事实提供专业对象；滴天髓式着落门不得明确失败。强根源为原局已有“载体—对象—作用—承接”完整链；弱根源为载体和对象可定位但链、承接或缺陷待补；无根源为孤立十神、单字类象、行业联想或完全依赖岁运临时拼合。
- 岁运完成方式：卡内冻结为激活已有、补全潜在、修补缺陷、临时替代、无效补全；这些名称沿用当时此前已冻结的全局五种完成方式，F01 卡内未逐项重展开其通用定义。可直接证明的卡内限制仅为：临时替代不得输出稳定技术职业身份，无效补全必须弃权，现实技术履历不得回写原局根源。
- 有限落点：状态替代为具有明确判断与裁量的技术实施／调试／维修／专业操作，以及以专业意见为交付物的咨询／评估／审计／方案支持；事件替代为由辅助执行升级为独立诊断／设计／核算／审查，以及取得必要资质或授权并实际扩大专业裁量。弱命中限于同域不同对象、技术支持但未独立负责、仅有训练资质或持续性不明；事后不得新增第四落点。
- 四维覆盖：理论家族强、现代传承强、中粒度功能强、具体职业落点部分；强覆盖只表示证据链足以进入候选，不表示任意命盘成立或预测概率。
- 反证与禁推：专业裁量或职责不成立、用神无着落、结构失当、主产出实属销售／管理／流程／原创研究／医疗处置、名义技术头衔无实际任务，均削弱、拒绝或转查相邻功能。F01 的防矛盾只以这些反证和禁推体现，不扩写 F03 专门四条防矛盾条款。

### 4.2 F02 研究创新与知识生产

- 恢复状态：完整恢复；原闭区间未明示 T0/T1/T2，输出精度保持缺失。
- 冻结总定义：围绕未知问题、知识缺口或现有方法局限，持续开展观察、比较、试验、推演、归纳、建模、验证或体系重构。状态层判断是否持续承担研究、研发或系统性知识生产职责；成果层判断是否形成可复用、可检验或被共同体承接的新增知识、方法、模型、技术或系统成果；研究状态成立不等于创新成果形成。
- 内部标签：知识研究与理论生产、技术研发与方法创新仍属一个 F02，可一主一副，但证据不得互相替代。
- 现实硬门与双卡：状态五门为明确未知对象／缺口／目标、系统持续过程、稳定职责或正式项目、现实承接、排除单纯执行／教学／传播／成熟技术应用，分 S1 参与、S2 独立、S3 主导。成果五门为新增性、可识别产物、个人实质归属、同行／组织／实践／市场／临床／工程验证、共同体或现实承接，分 O1 局部新增、O2 可复用、O3 体系性突破；奖项、专利和职位不自动升级。
- 结果与竞争：统一按主对象—主动作—主产出裁决。既有知识解决已知问题归 F01；按流程测试交付归 F03；面向学习者传递归 F10；诊疗患者归 F11；面向受众制作发布归 F12。每项功能须独立说明对象、动作、产出，同一证据不得重复抬高置信度。
- 理论双门／根源／岁运：ZP、DT、QM、MB 各保留家族角色，以家族内作用链、跨家族同功能互证或反证、现实状态五门或成果五门编译。强根源要求载体明确、对象定向、单一家族输入—加工—输出链完整、输出有着落且可持续；弱根源为链缺一环、混杂受制、着落不足或只具局部模块；无根源为只有聪明学历文章口才兴趣、成熟解决／教学／传播链，或任何单一家族均不能成链。强根源优先激活既有或修复缺陷；弱根源可补全潜在、修复缺陷或临时替代；无根源只允许临时替代。任何命理完成仍须现实硬门，现实成果不得回写根源。
- 有限落点：中心为截至求测日持续承担有明确对象、系统过程与现实承接的研究、研发或知识生产职责；替代为知识研究与理论生产、技术研发与方法创新。成果事件另卡判断，不作第三替代。仅进入机构、外围参与、普通写作、未验证改进或相邻功能事实只能弱命中或邻域命中；职责以行政、教学、传播、例行执行或成熟技术应用为主，无明确对象／过程、个人贡献不清、复述搬运或长期无着落，构成反证。
- 四维覆盖：理论家族强、现代传承强、中粒度功能部分、具体职业落点最小。
- 禁推：聪明博学学历、单一印／食伤、研究身份、普通论文综述教材、未核验个人贡献的专利奖项、例行实验测试、授课传播均不得直接推出 F02 或创新成果。F02 的防矛盾只以状态—成果分账、反证和十条禁推体现，不扩写 F03 专门四条防矛盾条款。

### 4.3 F03 生产运营与流程执行

- 恢复状态：完整恢复；原闭区间未明示 T0/T1/T2，输出精度保持缺失。
- 冻结总定义：命主依据既定目标、流程、标准和资源约束，持续实施生产、加工、设备运行、流程操作、质量执行或现场交付，把材料、设备、信息、订单、服务请求或现场条件稳定转化为可验收产品、服务或阶段成果，并维持节奏、质量、产能、安全、时效与流程连续性。它判断按既定方法实现稳定转换与连续交付，不等于在工厂工作、体力劳动、管理或经营。
- 双内部标签：生产加工与现场执行、流程运营与连续交付；可一主一副，按主要转换对象与主要产出定主，同一事实不得重复计权，质量检测与生产计划按实际职责归类。
- 现实硬门与双卡：状态六门为对象、既定流程、实际执行、可核验标准、持续重复、排除相邻功能，分 S1 参与执行、S2 独立完成工序／运行单元／交付闭环、S3 关键工序／核心运行单元；S3 是运行关键性而非管理层级。事件六门为基线、可核验变动、个人归属、可观察结果、持续后果、反事实；方向为 START、EXPAND、IMPROVE、DISRUPT、CONTRACT、RECOVER、REPLACE、EXIT，复用轻微／显著／重大／转折性影响。只有核验且有持续后果的事件更新状态。
- 结果与竞争：按主对象、主动作、主产出、首要责任拆分职责。非标准异常诊断归 F01，新工艺研发验证归 F02，既定工艺稳定执行归 F03，人员任务节点资源协调归 F04，盈亏资金客户供应平台资源承担归 F08；同岗位可一主一副，但同一职责事实不得重复增权。

- 理论双门／根源／岁运：同派异质结构合法性与知识经外化指向教育对象的功能完成双门；R1 直接根源、R2 单一缺口、R3 背景支持及非根源／弃权按因果距离裁决；五种完成方式每派每链每窗唯一，R3 不得直接完成。
- 有限落点与覆盖：一个中心、最多两个同域同方向替代，另记弱命中、反证、排除和分类缺口；覆盖采用 D1 内容—对象、D2 动作—归属、D3 功能闭环、D4 时态有效性四维 C0–C3 剖面，不求和。
- 输出／验证接口：快照中的 T0/T1/T2 是冻结起点、观察窗口、截止日裁决时点，不是共同定义中的输出精度，不得混用。
- 防矛盾：八层证据卡只允许从身份时点到结果竞争裁决单向推进；失败就地终止；明确停课或转职优先，理论与现实双向禁止回写。

### 4.11 F11 医疗照护与身心风险处置

- 恢复状态：完整恢复。
- 冻结总定义：命主面向可识别个人，或边界明确且具有共同身心健康／安全风险的群体，实际实施评估、诊断、治疗、手术、护理、康复、监测、急救或危机干预之一；动作必须归属于命主，并与患者侧经历、职业身份、机构场域、团队成果及相邻功能区分。持续照护是基础处置链上的增强形态，不是普遍前提。
- 现实硬门与双卡：风险对象、至少一项过门处置动作、命主归属三项闭合；六类角色仅用于归属审查。基础处置与持续照护增强分链；状态 S0–S3、事件 E0–E3 独立，历史事件不生成当前状态。
- 结果与竞争：四类有限方向覆盖建立／进入、增强／稳定、减弱／暂停／终止／转离、阶段性借象；研究、经营、销售、行政、教育、传播、一般保健、普通安慰、命理预测、宗教处置和患者侧事实均须优先作最强竞争解释。
- 理论双门／根源／岁运：理论对象门 O、作用门 A、同派同局同链定向关系及领域／对象／作用方向／承载四节点；强、弱、无根源各派独立评级；五种完成方式遵守根源配对，临时替代不等于现实弱命中。
- 有限落点与覆盖：每次一个中心、最多两个同域同方向替代，另记弱命中、反证、排除与 `TAXONOMY_GAP`；四维为理论家族部分、现代传承强、中粒度功能强、具体职业落点部分。
- 输出精度：T0 医学关联层；T1 中粒度功能层；T2 具体角色／职业／专科层。默认最高 T1，T2 受限，须通过相应必要门；T 层不得与根源、岁运、S/E、覆盖或置信度互相回填。
- 防矛盾：安全风险限身心健康处置语境，危机处置限实际身心风险干预；现实／理论／时序／输出四层防倒灌，负证优先、最强竞争解释优先、弃权优先；冲突不能消歧则未知或人工复核。

### 4.12 F12 内容生产、传播与影响

#### 总定义与 P/D 双路径

F12 识别命主对可识别、已外化且可被他人理解或感知之内容／表达成果的直接生产或传播功能；生产以内容形成并完成外化为核心，传播以命主实施发布、呈现、播送、分发等动作并具有可识别受众或现实可达方向为核心；实际触达与内容影响仅作独立增强，不是基础成立条件。

生产路径 P 的四项必要门是：可识别内容／表达成果、命主实际创作／编写／实质编辑／录制／制作完成、成果达到可供他人接收的外化形态、动作归属命主。传播路径 D 的四项必要门是：可识别内容、命主实际发布／呈现／播送／分发或传播、可识别受众或现实可达方向、动作归属命主。任一路径独立闭合即可成立基础 F12；未发布但已外化完成只成立 P，实际触达与影响均非基础门。

内容对象不包括思想、主题、素材、数据、空白模板、商品本体或未完成草稿。生产动作限创作、编写、形成实质内容的编辑、录制和制作完成；传播动作限发布、公开呈现、播送、策展式展示、面向受众分发及有归属的转述／评论。纯搬运、物流、设备／平台维护、排版印刷、被采访／报道／被动出镜、点赞收藏和私下转发不成立。共同创作按可核验个人贡献归属，团队成果不得整体归命主；纯传播组织或管理不得借团队成果补 F12。

#### P0–P3／D0–D3 状态卡与事件卡

| 轴 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| P 生产状态 | P0 无证据 | P1 单次或阶段性完成 | P2 重复但不稳定 | P3 持续稳定生产 |
| D 传播状态 | D0 无证据 | D1 单次或阶段性传播 | D2 重复但不稳定 | D3 持续稳定传播 |

生产与传播状态分别登记。L1 实际触达、L2 内容影响均不抬升 P/D；职位或机构存续不证明动作持续。

事件卡登记：开始创作、内容完成、实质编辑完成、录制／制作完成、首次发布、再次发布／再版、公开呈现／播送、分发扩展、暂停、恢复、终止、撤回／下架、转离直接动作、实际触达、影响出现／扩大／减弱。一次事件不自动生成 P3/D3，历史事件不证明当前状态；同一作品的生产、发布、触达与影响按各自时间点分账。

#### L0–L2 结果层

- L0 基础成立：P 独立闭合，或 D 的内容、传播动作、受众／可达方向和归属闭合；
- L1 实际触达：有独立证据证明受众实际接收、观看、收听、阅读或参与；
- L2 内容影响：有独立证据证明特定内容导致或实质促成受众认知、态度、情绪、讨论、决策或行为变化。

L0、L1、L2 不互补、不倒灌；公开可达不等于实际触达，实际触达不等于内容影响。规模、粉丝、点击、获奖、喜爱、名气、收入、争议或负面曝光只登记其直接证明事项。私人一对一表达默认不算传播；组织内部受众可成立，但行政通知、制度执行和教学分别优先检查 F05/F06/F10。

#### 竞争边界与最强竞争解释

竞争按“动作切片＋直接功能目的＋各自过门＋有限并存”裁决，不预设唯一竞争功能：新知识／方法的研究产出归 F02；组织项目与资源协调归 F04；以服从、程序参与或规则实施为核心的宣传优先 F05/F06；以获客成交为核心的广告、直播或演讲优先 F07；平台、媒体机构或文化公司的经营承担归 F08；以特定学习者掌握为目标的教学归 F10；一对一健康／危机干预表达由 F11 吸收。艺术表演只有可识别表达成果、命主呈现责任及受众／可达方向闭合时才过 F12。竞争解释更完整则 F12 不成立；各动作独立闭合才允许并存；不能消歧时输出未知或人工复核。

#### 理论 O/A 双门与三级根源

理论对象门 O 要求同一派、同一命局在组合语境中形成可定位的内容／表达对象，并能区分思想能力、素材、载体、职业名与已形成内容。理论作用门 A 要求同一派、同一命局出现命主对该对象的形成、编辑、呈现、发布、连通、扩散或面向受众作用之一，并可定位作用方向与承载。生产候选闭合“内容对象＋形成／完成作用”；传播候选闭合“内容对象＋传播作用＋受众／外部可达方向”。禁止跨派、跨局、跨案例拼 O/A，禁止现实职业反馈或单符号堆叠补门；理论不得回填现实 P/D 或 L0–L2。原会话没有独立统一的原始语料门字段裁决，因此机器附录中的 `source_gate` 保持空缺。

根源以内容对象、作用方向、受众或外部可达方向、承载四节点为尺度，生产与传播分别评级：

- 强根源：原局同派同局同链闭合 O＋A，并具备对应 P 或 D 的全部核心节点；
- 弱根源：已有可定位内容对象与同方向作用基础，只缺一个非核心连接、外部可达方向或稳定承载；
- 无根源：O 未闭合、未见命主同方向作用，或只有食伤、印、纸张、丙丁、网络、媒体、名气、职业等关联象。

生产强根源不自动成为传播根源，传播候选也不能跳过内容对象；各派独立评级，现实职业、作品、P/D、L0–L2 及后验岁运不得升级根源。

#### 五种岁运完成方式

生产链与传播链分别裁决：

- `ACTIVATE_EXISTING`：原局已闭合对应 O＋A 与核心承载，岁运只使既有形成、发布或呈现节点到位／发动；
- `COMPLETE_LATENT`：已有内容对象与同方向作用基础，岁运只补一个缺失连接、外部可达方向或承载；
- `REPAIR_DEFECT`：已有对应链但形成、编辑、呈现、发布、连通或承载受阻，岁运解除障碍或恢复作用；
- `TEMPORARY_SUBSTITUTE`：岁运临时引入相似对象、媒介、平台、受众或作用关系，只支持阶段性借象；
- `INVALID_COMPLETION`：只有表面关联，或对象错误、动作不归命主、无受众方向、跨派拼门、竞争解释更强。

每条路径、每一时窗只登记一种主完成方式；无根源不得激活已有，无根源的表面补全原则上降为临时拼接。岁运不得回写根源、现实 P/D、L0–L2、作品或职业事实。

#### 有限现实落点

四类方向保持生产／传播分账：建立／进入以首次完成过门外化内容或首次实施过门传播为中心；增强／稳定以 P 或 D 的持续性、责任范围或内容承接明显增强为中心；减弱／暂停／终止／转离以已核验 P/D 实质暂停、终止或退出为中心；阶段性／临时借象以有限窗口内完成过门内容或传播但未形成稳定路径为中心。每类最多一个中心、两个同域同方向替代，并登记弱命中和中心关闭约束；L1/L2 不替代现实落点。只有计划、能力、职业、机构、平台、作品名、名气、粉丝、点击、获奖、收入、争议、团队成果或被报道均为共同反证。未覆盖事实只登记 `TAXONOMY_GAP`。

#### 四维覆盖与输出精度

覆盖冻结为：理论家族部分、现代传承强、中粒度功能强、具体职业落点部分。四维独立、不合并、不互补；同源案例去重，现代作者数量不抬升理论家族覆盖，职业细分类默认降级，覆盖不得回填 O/A、根源、岁运、P/D、L0–L2、现实证据或置信度。

`T0` 只能输出“存在内容形成或传播方向候选”，不得断定现实生产、发布、触达、影响、具体角色或职业。`T1` 将生产与传播分账，须闭合现实门、同派同局同链 O/A、根源与岁运完成方式，才可输出建立、增强、减弱或临时出现，不得越级至媒介、内容类型或职业。`T2` 是记者、编辑、作家、主持、演员、主播、自媒体、宣传岗位、文章、节目、影像等具体角色／职业／媒介／类型，须另有同派细分类限缩、独立现实动作证据且已排除最强竞争解释。默认最高 T1，T2 受限；职业反馈、机构平台、名气粉丝、四维覆盖、置信度或单符号均不得升级 T 层。

#### 十二组反例与四层防矛盾门

1. 有思想无外化成果：不成立；2. 有完成稿未发布：只成立生产；3. 转载／转述无可核验归属：不成立；4. 纯排版、印刷、物流、设备或平台维护：不成立；5. 被采访、被报道或被动出镜：不成立；6. 团队作品但个人贡献不可核验：不归命主；7. 媒体／文化机构任职但无直接动作：不成立；8. 以成交为核心：F07 优先；9. 以学习者掌握为核心：F10 优先；10. 研究成果本身归 F02，另有独立外化制作／发布动作才并存 F12；11. 以服从、程序或规则实施为核心：F05/F06 优先；12. 粉丝、点击、获奖、名气、收入、争议或负面曝光不补基础门。

现实层禁止对象、动作、归属、受众互补；理论层禁止跨派、跨局、跨案例拼 O/A；时序层禁止事件回写根源、历史事件证明当前 P/D、L1/L2 抬升 P/D；输出层禁止覆盖、置信度、职业反馈或单符号升级 T 层。冲突按负证优先、最强竞争解释优先、弃权优先；无法裁决时输出未知或人工复核。

## 5. 跨功能竞争与并存

竞争裁决必须比较：

```text
首要责任
→ 主要动作
→ 直接对象
→ 主要交付
→ 主要不确定性
→ 稳定投入
→ 最强竞争解释
```

同一事实允许多功能并存，但每个功能必须拥有独立对象、动作、归属与闭合链；不得把一个功能的成果、平台或身份借给另一个功能补门。

已恢复的主要竞争关系：

- F03/F04：稳定转换与连续交付 vs 行动协同与整体交付；
- F01/F08：专业技术输出 vs 经营单元资源、风险、损益与存续承担；
- F03/F08：重复流程与连续交付 vs 经营单元资源、风险、损益与存续承担；
- F04/F05：任务行动关系 vs 组织身份关系；
- F04/F06：行动协同 vs 公共规范效力；
- F04/F08：任务交付闭环 vs 经营存续闭环；
- F05/F06：内部成员／任职身份效力 vs 外部公共规范效力；
- F05/F08：组织身份治理 vs 经营单元资源、风险、损益与存续承担；
- F07/F08：交易进程推进 vs 经营单元资源、风险、损益与存续承担；
- F08/F09：经营职责链 vs 资本／信用配置与风险位置；此跨卡边由 F09 侧区间冻结，不作为 F08 卡片自有竞争边；
- F09、财富结果与一般债务承受分别过门；
- F10、F11 与研究、经营、销售、行政、教育、传播等混合事实按动作切片独立过门；
- 研究成果本身优先 F02；独立外化制作或发布动作可并存 F12；
- 纯组织协调优先 F04，不得借团队内容成果补 F12；
- 行政宣传以组织成员、程序或规则实施为核心时，F05/F06 优先；
- 以成交为核心时 F07 优先；以学习者掌握为核心时 F10 优先。

## 6. 反证、弃权与人工复核

出现以下任一情况，应降级、弃权或进入人工复核：

1. 没有任何一家形成完整原局链；
2. 现实硬门不满足；
3. 只有职位、行业、机构、十神或性格标签；
4. 具体事件缺少原局、大运、流年作用链；
5. 大运或流年只有年份标签，没有作用对象和机制；
6. 真冲突无法裁决；
7. 无根源却宣称激活既有功能；
8. 无效完成仍被输出为主事件；
9. 只有检索命中、索引规则或二手结构化记录，没有可定位原文；
10. 候选依赖跨派残件拼装。

真冲突至少要求同一功能、同一时间层、同一作用对象、同一语义字段和相同前提下结论相反。高敏感或高风险事项应优先人工复核。

## 7. 出处索引与证据纪律

出处索引只记录可定位来源，不把检索命中数、材料数量或同源复述数量转写为证据强度。每项来源应尽可能包含文件、章节或行号、支持字段、适用边界与反证用途。

原始引文保留在原始语料或专门来源记录中；机器附录只保存索引与角色，不复制大段引文。无法回溯到原始语料的二手规则，不足以单独通过原始语料证据门。

2. F01–F03 已按原 Session 闭区间终局裁决完整恢复；原区间未明示的 T0/T1/T2 保持缺失；
3. F04–F11 的追溯或绑定缺口须保留；没有直接终局裁决的输出精度或覆盖字段保持缺失；
4. 不得从旧交接、共同条款、功能名、F12 或后验摘要反推缺失值；
5. 机器附录不得表达可执行条件分支或优先级算法；
6. 对判定逻辑的生产实现必须另行设计、评审和测试；
7. 修改流程遵守 [`00-OVERVIEW.md`](00-OVERVIEW.md) 第十节。
