# 职业路径误差分析 v1

> 本报告分析 P 系列 10 案职业路径挑战集。标注阶段只使用既有冻结预测、人工标签与反馈事件；未读取 `cases/shuru-input.md`，也未用四柱反推真值。
>
> 下述“原局倾向”均是由现实轨迹提出的**待盲盘证伪假设**。机制只有在命盘输入上可独立计算时，才允许进入分类器。

## 一、挑战集构成

| 类型 | 案例 | 观察目的 |
|---|---|---|
| 真值经营且预测正确 | P-2026-001、P-2026-035、P-2026-037 | 验证哪些经营信号对应真实自主承担盈亏 |
| 真值任职但预测经营 | P-2026-041、P-2026-058、P-2026-073 | 定位最危险的所有权误判 |
| 真值任职且模型弃权 | P-2026-004、P-2026-055 | 区分合理不确定与漏用位置/大运 |
| mixed 路径转换 | P-2026-047、P-2026-051 | 建立当前状态、历史路径与转换过程的分账 |

冻结基线在 37 个严格二分类样本上的 balanced accuracy 为 42.50%，任职 recall 为 25.00%，经营 recall 为 60.00%，覆盖率为 54.05%。主要问题不是“不会发现财路”，而是把财富、业务、流动与自主性过度解释成企业所有权。

## 二、逐案四问

### P-2026-001｜经营命中

1. **原局支持哪些职业路径？** 反馈轨迹支持自主经营先验：外出经商、致富、损财后重新起家，路径跨年份重复。待盲盘检验的结构表达是食伤生财成链并有比劫协作或主体做功。
2. **哪个大运兑现或受阻？** 丙寅运于 1997 年兑现经商致富，2000 年经营成果受损；丁卯运于 2002 年重新起家。
3. **截止反馈时点的现实状态？** entrepreneurial，且不是一次性副业。
4. **适配器为什么对？** 高经营分差在此对应真实自主交易闭环；有效的是“经营—受损—再经营”的主体做功，不只是财星多。

### P-2026-035｜经营命中

1. **原局支持哪些职业路径？** 支持经营倾向，但经营质量和财富留存弱；待检验结构为食伤生财可用但制化不完整。
2. **哪个大运兑现或受阻？** 丁亥运已见经商发展，同时财来财去、事业多波折。
3. **截止反馈时点的现实状态？** entrepreneurial，但稳定性不足。
4. **适配器为什么对？** 方向判断正确；不足是路径分类没有把“是否经营”与“经营是否赚钱、是否稳定”分开。

### P-2026-037｜经营命中

1. **原局支持哪些职业路径？** 支持经营，同时组织任职容易受阻；待检验结构为食伤财做功成立、官杀约束失衡或不能形成稳定组织容器。
2. **哪个大运兑现或受阻？** 乙巳运兑现地下、无证经营，并同时出现事业挫折和被迫辞职。
3. **截止反馈时点的现实状态？** entrepreneurial，附带合规风险。
4. **适配器为什么对？** 自主做功落到真实交易。这个案例说明经营成立不等于经营合法，也不等于财富层级高。

### P-2026-041｜任职误判经营

1. **原局支持哪些职业路径？** 现实轨迹强烈支持组织内任职；待检验结构为官杀—印绶—主体位置成链。
2. **哪个大运兑现或受阻？** 丁未运发生双规，是组织纪律和官杀约束的兑现，不是经营开启。
3. **截止反馈时点的现实状态？** employed：公路系统副处级，反馈时遭党纪调查。
4. **适配器为什么错？** 缺**位置**和**大运制约**。活跃财路或自主做功不能覆盖已成立的官印组织位置；官杀大运当令时还应抑制经营判定。

### P-2026-058｜任职误判经营

1. **原局支持哪些职业路径？** 支持组织任职，表现为多个公办单位内的岗位迁移；待检验结构为官印组织链稳定、职能星可变化。
2. **哪个大运兑现或受阻？** 反馈无可靠大运。约 37 岁后事业财运下滑、2013 年后家庭财运改善，但没有经营身份转换。
3. **截止反馈时点的现实状态？** employed：教师、财务，均在公办单位。
4. **适配器为什么错？** 缺**位置、标签定义与做功**。做财务不等于拥有生意，换单位不等于创业，家庭财运改善也不等于命主经营。

### P-2026-073｜任职误判经营

1. **原局支持哪些职业路径？** 支持组织任职；待检验结构为官杀印绶成链并能承接选拔、入职、晋升。
2. **哪个大运兑现或受阻？** 原反馈没有大运字段；现实顺序是计划内本科、毕业后任乡镇干部、2018 年前升职。
3. **截止反馈时点的现实状态？** employed，且组织内晋升已兑现。
4. **适配器为什么错？** 缺**位置与制化优先级**。经营分高不能越过官印链；自主经营还必须要求食伤生财与比劫/主体做功的联合证据。

### P-2026-004｜任职弃权

1. **原局支持哪些职业路径？** 反馈只支持低置信任职先验；待检验结构未知。
2. **哪个大运兑现或受阻？** 甲辰运完成大学并参加工作。
3. **截止反馈时点的现实状态？** employed，但岗位、单位和发展未知。
4. **适配器为什么错？** 主要缺**阶段位置**；两类分数接近时弃权本身合理。本案应保留为信息稀疏边界，不应用真值反推强规则。

### P-2026-055｜任职弃权

1. **原局支持哪些职业路径？** 支持组织任职；待检验结构为官印成链而表达、经营做功偏弱。
2. **哪个大运兑现或受阻？** 辛卯运 31 岁进入体制，39 岁获小职务。
3. **截止反馈时点的现实状态？** employed、公职，并明确否认开店。
4. **适配器为什么错？** 缺**大运和位置**。静态分差不足时没有使用大运把组织先验提升为现实路径；不过盲推时若原局和大运相悖，仍必须弃权。

### P-2026-047｜mixed 转换

1. **原局支持哪些职业路径？** 支持任职和经营双路径假设；待检验结构为官印链与食伤财链并存。
2. **哪个大运兑现或受阻？** 2012 年丙午运从长期打工转为创业；丙午转乙巳期间创业仅勉强维持。
3. **截止反馈时点的现实状态？** mixed：历史长期任职，当前创业；转换点为 2012 年。
4. **适配器为什么错？** 缺**标签定义、大运与现实位置分账**。将 mixed 一律转成 abstain 丢失了有效状态，也混淆“路径已切换”和“经营质量差”。

### P-2026-051｜mixed 转换

1. **原局支持哪些职业路径？** 支持任职、经营双路径和反复转换；待检验结构为两链并存但经营制化不足。
2. **哪个大运兑现或受阻？** 庚寅运 2006 年离职合伙经营，随即亏损；2007—2013 跑业务，2012 较好，2013 转差并寻求转型。
3. **截止反馈时点的现实状态？** mixed / transitioning；转换窗口为 2006—2007。
4. **适配器为什么错？** 缺**标签定义、做功与大运**。mixed 被压成 abstain；经营路径成立与经营获利没有分开，当前转型状态也无表达位置。

## 三、跨案共性机制

### 机制 A：先判组织位置，再判财富活动

三个“任职→误判经营”案例都有强组织位置：副处级、公办单位、乡镇干部。共同错误是把财星、业务能力、收入流动或自主性等同为企业所有权。

**事前命理表达：** 若原局存在官杀有根、有制化并能生印，印绶承接主体，形成“官杀→印→身”或“官印相生”的稳定链，则先增加任职分。财星存在只描述资源与收益，不自动覆盖组织位置。

### 机制 B：经营必须有“输出—交易—承担盈亏”的做功闭环

三个经营命中案例不是只有钱财事件，而是有经商、无证经营、重新起家等主体行为。P-2026-058 做财务、P-2026-041 有经济权力、P-2026-073 买房，都不能构成经营。

**事前命理表达：** 经营分必须由食伤生财成链触发，并要求比劫、日主或主体宫位参与做功；仅财星多、财旺、流通路径多不能触发经营。比劫只在配合食伤财链时加分，孤立比劫不等于创业。

### 机制 C：大运是路径开关，不是统一加分器

P-2026-055 在辛卯运进入体制并获职；P-2026-041 丁未运兑现组织处分；P-2026-047 在丙午运由打工切换创业；P-2026-051 庚寅运离职合伙但经营受阻。大运决定的是哪条原局路径被打开、抑制或迫使转换。

**事前命理表达：** 大运官杀当令且有印绶承接时，增加任职并抑制经营；大运食伤财到位且主体能承载时，开放经营。若大运方向与原局优势相反，不强行改判，返回 `mixed_signal` 弃权。

### 机制 D：路径、质量、状态必须分账

经营可以成功、勉强维持、无证经营或反复亏损；任职可以升职、调岗、被处分或失业。它们首先仍是路径，其次才是质量。P-2026-047 和 P-2026-051 还证明历史路径与当前状态可以不同。

**事前命理表达：** 原局只产出 `NatalCareerInclination`；大运产出开放/抑制上下文；现实状态由截至求测日的已核事件保存。分类器若没有现实事件，只能推断倾向和大运约束，不得虚构已发生的任职或创业事实。

## 四、至少三个可编码判别器

### 判别器 1：官杀印绶组织链

**输入特征：** 日主十神映射、官杀出现及根气、印绶出现、官生印/杀印相生链、食伤对官杀的制化状态。

**规则草案：**

- 官杀有根且印绶承接：任职 `+2.0`；
- 官杀透出并官印相生：任职再 `+1.5`；
- 官杀混杂且无制、印不承接：不加组织稳定分；
- 食伤强力破官且无印救：任职 `-1.0`，但不自动转经营。

**事前性：** 全部由四柱结构计算，不读取职业字段。

### 判别器 2：食伤生财 + 比劫/主体做功链

**输入特征：** 食神伤官出现、财星出现、五行相生链、透藏与根气、比劫是否参与生泄/合财/制财等做功。

**规则草案：**

- 食伤可用且直接生财：经营 `+2.0`；
- 财星有根、食伤链连续：经营再 `+1.0`；
- 比劫参与且未形成纯夺财：经营再 `+1.0`；
- 只有财星而无食伤输出链：经营最多 `+0.5`，不得单独触发。

**事前性：** 只读取命盘结构；不会把岗位为财务或工资高误当经营。

### 判别器 3：大运官杀经营抑制器

**输入特征：** 当前大运干支对应十神、官杀是否当令/有根、原局印绶能否承接、原局经营链与大运方向是否冲突。

**规则草案：**

- 大运官杀当令且印绶承接：任职 `+1.5`，经营 `-1.5`；
- 大运官杀强而无承接：不直接判任职，记录组织压力；
- 原局经营领先但官杀运强制约：返回 `mixed_signal`，不得因财星多继续判经营。

**事前性：** 仅用四柱、大运序列和截止日期。

### 判别器 4：双链冲突与路径转换候选

**输入特征：** 官印组织链分、食伤财经营链分、当前大运相对两链的开关方向。

**规则草案：**

- 两类分差 `< 1.5`：弃权；
- 原局优势与大运方向相悖：弃权原因 `mixed_signal`；
- 两链均强且大运发生方向切换：倾向标记为双轨，不能把 `mixed` 当错误数据；在没有现实事件时不得断言已转换。

**事前性：** 只输出结构候选和弃权原因，不读取反馈来决定当前身份。

## 五、实现边界

1. 分类器只能消费四柱、大运和截止日期，禁止读取 known facts、occupation、标签或反馈文本。
2. `NatalCareerInclination` 是先验，不能冒充现实状态。
3. `RealityCareerStatus` 若无独立核验事件，应为 `unknown`；纯命盘函数不得伪造 `employed` 或 `entrepreneurial`。
4. mixed 的正式含义是双轨并存或已经发生路径转换；原型无法观察现实事件时，可通过 `abstain_reason="mixed_signal"` 表达结构冲突。
5. 评分参数在首次 holdout 运行前冻结；首次结果不达门槛则诚实 FAIL，不允许回看测试集继续调参。
