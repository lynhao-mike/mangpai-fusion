# 裁决日志（过程记忆）v1

> 目的：保存“当时为什么这么判、后来为什么推翻”，避免重构时重复老路。
> 与另外两套文档分工：
> - **本日志** = 过程记忆（裁决、选项、否决理由、后果、链接）；
> - `docs/reviews/failure-ledger-v1.md` = 错误记忆（症状、证据、规则、守护）；
> - `docs/specs/*` = 当前契约（A+ v1.3 等）。
>
> 规则：**append-only**；旧条目不改，更正另起一条；每次裁决/重大转向 24h 内追加；
> 中枢负责写，子代理可起草但中枢验收；不写日志的裁决不算完成。
