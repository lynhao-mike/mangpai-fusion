## 二、项目是什么

八字（四柱）分析系统，融合四派盲派（高德臣、段建业、杨清娟、任付红）与子平、滴天髓。

**产品目的（人类原话）**：

> 「我希望像一个真正的命理师一样，能熟练运用各流派八字理论，用于真实八字的分析。」
> 「分析八字，不管使用哪个流派，最终目的还是为了能真实进行命理分析预测。」

**唯一重构判据**：这次重构让**哪一条断语**从「算不出来」变成「算得出来」？

技术栈：Python 3.11.16 / Windows / 解释器 `.venv\Scripts\python.exe`。

### 关键认知：盲派不用「用神」

原文（`theory/raw/duan/d01-deep-read.md:106`）：

> 「**用是什么？用是我的目的、我的追求**……需要注意的是，**这个『用』与传统命理中的用神是有区别的**。」

同文件 `:110`：「**体用之『用』≠ 子平传统『用神』。这是 M1 与 M2/M3 划清界限的核心。**」

**所以「补用神层」是错的提案（已撤销）。** 不同流派的第一性判断不同：

- **盲派**：体用 + 宾主 + 做功成败
- **子平**：格局 + 用神
- **滴天髓**：气势流通 + 寒暖调候

### 盲派分析链（原文依据）

```
① 排盘 → ② 宾主（4层）→ ③ 体用（体=日主/印/禄/比劫；用=财/官杀；食伤双属）
→ ④ 做功（制用/化用/生泄/合用/墓用/复合）→ ⑤ 论成败（有势+有功、制得住/制死）
→ ⑥ 取象（宫位象+十神象+宾主象）→ ⑦ 落事 → ⑧ 应期
```

原文（`d01-deep-read.md:175`）：「只有势没有功不行，只有功没有势不能有大作为。」（注意：这是**富贵命**判据，不是通用成败判据）
