## 0. 一句话

**核心诊断接受**：现有 10 条产品规则是「盘面聚合特征 + 阈值切割」，丢掉了宫位/十神/体用做功的地址；
在最干净的 342 例婚姻标签上两条核心规则都无信号（+1.15pp / −4.80pp），继续洗财富/健康标签是在给死架构续命。
方向应切到「盘面地址级证据 + 婚姻应期（382 例 / 45.3% 基线）+ 单条理论忠实规则（342 例）」。
但复审有三处事实过期、一处统计功效算错；**冻结/删除产品规则需要人类签字，今晚不擅自改产品口径。**

## 1. 接受（不需要再讨论）

1. **架构错配**：`active_path_count=3`、`independent_signal_count` 这类去地址聚合特征，无法表达
   「某柱某神通过冲/合/制作用于某宫某神」。婚姻两规则在干净标签上零信号，是这条诊断的直接证据。
2. **停止标签工程扩测**：财富/健康 v2 门槛未过（债务 27.3%、健康 40.9% 含漏判），事业三分类不可判。
   继续 v3 或人工扩样，不能解决「规则表达」这一层的问题。
3. **应期优先**：382 例、标签是硬年份、基线 45.3%，是当前唯一能在 1–2 周内检验干支流年引动是否有真实预测力的靶子。
4. **三态输出**：`untriggered / confirmed / countered_resolved`，且每一态强制带盘面地址。
   「有忌象但得救应」应作为独立断语输出，而不是把 185/965 静默压掉。这是比现在 `outcome=fail` 更好的产品语义。
5. **first proof 用应期**，而不是继续在静态标签上做两比例。

## 2. 更正（复审的事实/数字已过期）

1. 「其余 4 条（财富 2、健康 2）条件原子构成需人工核对」——**不需要**，仓库里已展开：
   - `DUAN-EVENT-WEALTH-DEBT-V1`：`has_wealth / wealth_count / peer_pressure / support_drain_imbalance / branch_conflict_intensity / active_path_count`；
   - `GAO-WEALTH-DEBT-STRUCTURAL-CORROBORATION-V1`：`wealth_exposed / pressure_signal_count`；
   - `GAO-HEALTH-SYSTEM-RISK-{MODERATE,HIGH}-V1`：`predicted_label / risk_signal_count`（moderate 正条件同时含 `>=2` 与 `<=2`）。
   它们全是聚合代理，**没有一个绑定宫位/十神地址**——复审的判断成立，但不需要人工核对。
2. 「债务阳性 49、剔除 16 后 33；健康误判 71/131（54.2%）」——**v1 数字**。v2 已做到债务 **22** 阳性
   （含漏判 27.27%）、健康 **22** 阳性（40.91%），更少、更差；结论只会更强。
3. 「婚姻质量 59 例 / 43 例」——59 是**形态**标签的 scored（22/59）；质量标签 scored 是 **43**（23/43）。
   两个口径不要混用。
4. 「标签质量不是第一瓶颈」——**分域成立**：婚姻标签干净（7 例误判，~2%），所以婚姻上第一瓶颈是规则表达；
   但财富/健康/事业路径的标签本身不可用（>20%），对这些域，标签质量就是第一瓶颈。
   全局排序应写成：**婚姻域 = 规则表达；非婚姻域 = 标签可用性**。

## 3. 统计更正：experiment B（342 例、70/70、+12pp、p<0.05）功效不够

- 基线 54.4%，若触发组 66.4%（+12pp），每组 n=70：
  pooled p=0.604，SE=√(0.604×0.396×2/70)=0.083，z=0.12/0.083≈**1.45**，双侧 **p≈0.15**。
- 要在 α=0.05、80% power 下检出 12pp，需要 **每组约 250–260 例**；
  342 例里凑不出 70/70 之外的余量。
- 结论：**experiment B 不能按「70/70 + 12pp + p<0.05」预注册**；要么把效应门槛提到 ~24pp（不现实），
  要么放弃静态质量的「决胜实验」，只做描述性报告。**主证明点应放在应期（382 例、+8pp、p<0.01）**。
