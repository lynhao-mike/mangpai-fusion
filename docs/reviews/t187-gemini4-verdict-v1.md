## 3. A+（修正版）

**A+ = 可判断言强制表态 + 真歧义带冲突引文分流；固定类不混入动态主分母。**

- 输入：`case_id/chart_id/four_pillars/gender` + `target_relation{addr_a,addr_b,char_a,char_b,mechanism}`；
  **禁止 source.path/locator**。
- 三层：
  - **fixed gate 10**：克/生/化/墓；≥9/10；不进动态主分母。
  - **decidable dynamic 40**：冲/合/穿/刑；必须 actor→target 或 mutual；nj 记 miss；与 golden-20/holdout-20/fresh-40 三重零重叠；≥30 盘、≤2/盘。
  - **ambiguous 10**：真歧义/边界；允许 nj，但必须给**正反两条冲突原文/无功条件**的逐字 quote；单列，不进 40 分母。
- 引擎：事实 + 固定克/生/化/墓；**不发射党势方向**；刑只保留未戌刑/三刑齐的 mutual **候选**；自刑边不得当做功候选。
- Agent：检索原文 → 主宾/连体/库位 → 给方向与救应；decidable 逃 nj = miss；ambiguous 缺 conflict_quotes 或硬给方向 = 分流错。
- 阈值（草案，有内部不一致需拍板）：
  - pass：32/40 动态；Wilson LB≈65.2%；按 chart_id 聚类 ≥78%；比两条笨基线高 **8** 条（§5.2）或 **6** 条（§7 kill）；需统一。
  - 可判断言 nj 逃票 ≤4/40（10%）；>6/40（15%）kill。
  - quote 伪造/行内不可检出 >2/40（5%）kill。
  - 同一输入 3 次方向一致率 ≥90%。
  - 3 张卡：direction_known 3/3、rescue 已判 3/3、岁运快照；跨盘移植拒绝 ≥95%、同构异盘 ≥80%、单字反事实翻转。
- Kill：动态主集 <28/40（70%）或 <24/40 硬 kill；24–27 灰区；无原文推理基线增量不足；逃票/伪造超线；3 次一致 <90%；3 张卡移植拒绝 <80%。
