# 结局标签可行性裁决 v1（2026-10-29，中枢）

> 上游：T-148（婚姻应期集）、T-153（婚姻质量标签）、T-158（财富/健康标签 v1/v2）、T-159（事业标签可行性）
> 数据源：`cases/raw_feedback/parsed/real_cases_990.jsonl`（992 条 → 959 去重）
> 性质：这是**标签可行性**裁决，不是产品规则裁决；它回答「这批离线数据能测什么、不能测什么」。

## 0. 一句话

**这批离线语料只能稳定支持「婚姻质量」一个标签。** 债务与健康标签做了两版，含漏判错误率仍在
27% / 41%，过不了 20% 门槛；事业三分类不可判；角色变化只能建 `1/null`。
**10 条产品规则里，8 条无法用这批数据裁决。**

## 2. 为什么财富/健康标签救不回来

v2 已经把能想到的规则都上了：主体过滤（父母/配偶/子女/祖辈/姻亲）、否定窗口、严重度收紧、
房贷剔除、事件文本去重。结果：

- **债务**：阳性从 49 降到 22，残留假阳性 4（家庭债务、房贷跨句、公司破产、应收款），
  另有假阴性 2（否定窗口误伤「乙未」「钱没要回来」）。含漏判 27.27%。
- **健康**：阳性从 131 降到 22，残留假阳性 8（祖辈 4、姻亲 1、繁体「兄長」1、恋人 1、跨句主语继承 1），
  假阴性 1（「差点挂了 重病」被「差点」误杀）。含漏判 40.91%。

根因不是词表，是**中文长段落的语义结构**：零主语、跨句主语继承、第三人称、否定、繁体。
规则化的下一版（v3）仍要面对同一类问题；这不是再调几个词能解决的。

## 3. 对产品规则的直接影响

| 产品规则 | 需要的标签 | 现状 |
|---|---|---|
| 段派婚姻、杨派婚姻 | 婚姻质量 | ✅ 已测：均「无差异 / 样本不足」（342 例，CI ±11pp） |
| 段派财富债务、高派财富债务 | 债务事件 | ❌ 标签两版均不可用 → **无法裁决** |
| 健康中档、健康高档 | 严重健康事件 | ❌ 标签两版均不可用 → **无法裁决** |
| 事业角色变化 | 角色变化 1/null | ⚠️ 可建标签，但 0 侧是沉默；只能做「触发组精确率 vs 基础阳性率」，不能做两比例检验 |
| 事业受雇、创业、混合 | 三分类路径 | ❌ 不可判 → **无法裁决** |

**结论**：现有 10 条产品规则里，只有 2 条被真正量过（婚姻，无信号）；1 条可做弱检验（角色变化）；
**7 条没有可用的结果变量**。继续在规则/原子层加东西，无法改变这个事实。

## 4. 可选的下一步（需要人类/外部裁决，不是中枢能单独定的）

1. **v3 标签**：扩亲属词表（祖辈/姻亲/繁体/伴侣）、跨句主语继承、否定窗口避开干支与「差点挂了」。
   预计仍难过 20% 门槛；不建议默认做。
2. **人工标注 200–300 例**：最可靠，但成本高；可先标「债务危机」「危重健康」两个窄标签。
3. **窄标签**：只标「明确债务危机 / 危重住院」；阳性更少，统计功效更低，但误判可控。
4. **转应期**：382 例、事件年份标签，比质量标签可靠；但原局规则未过基线，接了应期只是放大噪声。
5. **停止对这些域下结论**：产品报告只保留已测的婚姻两条（且标注「无差异」），其余不宣称。

中枢倾向：**先让外部强模型裁决「人工标注 vs 转应期 vs 停」**，不要自动做 v3——v3 很可能只是把
同一个语义问题再交一次学费。
