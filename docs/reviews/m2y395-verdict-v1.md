## 0. 一句话

**复现成立，否证成立：字面规则「谁克谁 → 谁制谁 → 婚姻好坏」在这套题库上被否证。**
不是「样本不足」，也不是「方向对但证据弱」——两个独立计数口径下都低于多数类基线，

## 3. 判定（按预注册判据，不事后改）

`docs/reviews/verdict-chatgpt6.md:249` 的判据：95% 置信区间上界 < 基线 + 10 个百分点 → 否证。

- 边级：上界 **50.05%** < 54.24%（基线）< 64.24%（基线+10pp）→ **否证**
- 期级：上界 **51.19%** < 56.60%（基线）→ **同样否证**
- 连更严格的「上界 < 基线」都成立，不需要靠 10pp 宽限。

分支拆开看，失败不在「我制」：`self_controls` 55.9% 与常量猜 B（54.2%）几乎无差；
失败集中在 `other_controls` 的 12.0%——**「被制 → 婚姻不好」在数据里是反的**：
25 个被制命主中 13 个（52%）是一婚。

## 4. 这否证了什么、没否证什么

**否证了**：把「克向」当「制」，再拿它预测婚姻形态。这条链在 53 个独立期上不成立。

**没否证**（也不能靠这批数据区分）：
1. **「制」本身**。原文的「制」是制死/制净/党势，不是克向（`21.大连…:701`）。四态模型尚未实现，本次没测。
2. **「婚姻不好」这个结果变量**。题库的 A–E 是**婚姻形态**（未婚/一婚/离丧/二婚/多婚），
   不是**婚姻质量**。原文「被制→婚姻不好」未必等于「离丧/多婚」。这两条原因混在一起，
   本数据无法分离。

## 8. 2026-10-28 T-155 质量标签复测：样本不足

用 T-153 的 342 例「负面婚姻事件」标签重跑同一条方向规则（单位＝人，不是冲边）：

| 项 | 342 全集 | 敏感性 336 |
|---|---:|---:|
| 触发（日支有冲） | 60 | 60 |
| scored（self + other） | 43（20 + 23） | 43 |
| 弃权（no_ke） | 17 | 17 |
| 准确率 | 23/43 = **53.49%** | 53.49% |
| 基线（多数类 N） | 25/43 = **58.14%** | 58.14% |
| Wilson 95% | [38.92%, 67.49%] | 同左 |
| 判定 | **样本不足** | **样本不足** |

- `n_scored = 43 < 50` 硬门槛 → **样本不足**，既不能确认也不能推翻 §3 的否证。
- 也**没有达到否证**：Wilson 上界 67.49% > 基线 58.14%。
- 点估计 53.49% **低于**基线 58.14%——没有任何「方向有信号」的迹象，但样本不够，不下结论。
- 敏感性 336 与 342 完全相同：剔除的 6 例全部未触发（无日支冲），这套敏感性只能证明「判定不依赖这 6 例」，
  不能检验 scored 内的标签噪声。
- **结构瓶颈**：382 例里只有 67 人日支有冲（17.54%）；要 `n_scored ≥ 50` 需要更多带出生时刻的真实案例，
  现有数据不够。**四态模型暂不立项**——连方向层都测不出功效，往上叠模型只会更不可证伪。
