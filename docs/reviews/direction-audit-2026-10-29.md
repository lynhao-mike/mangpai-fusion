## 0. 一句话

**当前系统没有任何一条已验证的预测断语。** 最近三个否定结果（婚姻质量无差异、应期判死、
非婚姻标签不可用）加上地址审计（12 条婚姻信号 0 条有地址）指向同一个瓶颈：
**不是标签、不是样本量，是「理论 → 可计算形式」的表达**。
下一步我建议：**产品默认切到「解释层」**（只输出有盘面地址的结构与象，不承诺预测）；
**「新机制研究」作为独立项目**，先出机制规格 + 功效分析，经外部审计后再写代码。

## 2. 对外部复审路线的审计

**它对的**：
- 「聚合特征丢地址」被 T-164 量化证实：12 条婚姻信号 0 条有直接地址。
- 「停止标签工程」是对的：v1→v2 只把误判从 33%/54% 降到 27.3%/40.9%，根因是语义（第三人称/否定/跨句）。
- 「应期优先」在**功效**上是对的：K=3 功效 0.919，远好于 342 例质量实验。

**它没料到的**：
- 应期首测**判死**：R1–R4 不是「弱信号」，是**低于随机**（66 vs 68.84）。
- 这说明「只要用干支边」不够；**edge-count 也不是体用/宾主/制化**。
- 它提出的「地址级下一步」仍然是假设：R1–R4 已经用了 D.b/配偶星/岁运边，仍然失败；
  真正没测的是「制化成败 + 救应」这套**机制**，不是「有没有地址」这一个维度。

**结论**：外部复审的「地址损失」诊断成立，但「补地址就能救」**未被证明**，且刚被一个 address-adjacent
的 edge-count 版本打了一次脸。下一步必须把「地址」和「机制」分开谈。

## 3. 三个方向

### A. 解释层产品（推荐作为产品默认）

- 内容：四柱、十神、宫位、关系边、体用/宾主、做功候选——**全部是硬事实/可追溯的结构**；
  用命理师语言解释「这盘的结构与象」，**不承诺具体事件/年份**。
- 优点：不需要新的预测证据；事实层 481 盘 0 错；用户能立刻用；不违反「不编造」。
- 缺点：放弃「预测」这个产品承诺；需要重新定义报告价值。
- 成本：1–2 周（报告重组 + 地址级 evidence），不需要新模型。

### B. 数据优先

- 内容：收集更多带出生时刻的真实案例，把 342 例质量 / 382 例应期扩到能检出中等效应的规模。
- 功效：12pp 两比例、80% power 需每组约 250；若触发率 50%，总样本约 500+。
- 优点：解决「测不出」的问题。
- 缺点：**不解决表达问题**；如果机制错，更多数据只会更精确地测到「没信号」。
- 成本：数据采集/清洗，高；且当前 992 条已是历史积累，短期难翻倍。

### C. 机制优先（唯一可能恢复预测的路）

- 内容：放弃「聚合特征 + 阈值」和「edge-count」，按原文重写**一条**机制：
  体用/宾主 + 制化成败（制死/制净/制不净/制不住）+ 救应三态（未触发/成局/逢救应化解），
  强制绑定盘面地址（宫位 + 十神 + 作用边）。
- 前置：先写**机制规格 + 功效分析**（不写代码），经外部强模型审计。
- 优点：唯一有机会产生真实预测力的路。
- 缺点：高研究风险；1–4 周；可能再次失败；需要人类接受「可能没有结果」。
- 关键：**不要再用「加原子/加权重/换 K」的方式救 R1–R4**；那是同一个形式化。

## 4. 我的建议（按顺序）

1. **产品默认切 A（解释层）**：把「预测」从产品承诺里拿掉，直到有断语过预注册。
   这不是放弃，是把「已验证的事实」和「未验证的推断」分开——现在报告把两者混在一起，才是最大风险。
2. **C 作为独立研究项目**：先出 `机制规格 + 功效分析`，不写模型；外部审计通过后再开工。
   规格必须回答：机制是什么（不是「用了哪些边」）、地址怎么绑、结果变量是什么、n/power 多少、
   什么算证伪、什么情况停。
3. **B 只在 C 的功效分析说「现有 n 不够」时才做**；不要为了救一个错机制去收集数据。
4. **不做**：标签 v3、R1–R4 v2、加原子、翻 `matched`、自动启动 G2/G1、把 `statement` 说成地址版。

## 5. 如果做 C，机制规格的最小内容

- **因果故事**：哪一宫/哪一神，被谁制/化/合，成局还是破局，救应在哪。
- **地址绑定**：每个条件必须能写成 `宫位 + 十神 + 边 id/members/kind`；不能只有 `count`。
- **三态输出**：未触发 / 成局应凶 / 逢救应化解；不许把「救应」压成 `matched=False`。
- **结果变量**：先用 382 应期（硬年份）或 342 质量（干净标签），但必须先算 power；
  若 power <80%，写「不足以裁决」，不许硬跑。
- **否证条件**：例如「成局组 vs 未成局组的应期命中率差 < +8pp 或 p>0.20 判死」。
- **止损**：一次预注册只跑一次；不调参、不换 K、不换子集。

## 6. 什么会改变我的判断

- 出现一份机制规格，能给出**因果故事 + 地址绑定 + 功效 ≥80%**，且外部审计认为值得；
- 或出现新的数据源，把 342/382 扩到能检出 8–12pp；
- 或外部复审指出另一个我们没看到的瓶颈（例如「四柱排盘口径」而不是「表达」）。
