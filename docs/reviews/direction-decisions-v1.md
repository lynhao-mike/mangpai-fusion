## 3. 两份复审给出的、但尚未执行的建议

### 3.1 ChatGPT 6 的核心建议（最有价值）

**① 立度量契约（0.5 天，不改断语）**

`evaluate_claim` 现在把「结构不存在」和「结构存在但失败」都压成 `rejected`。应输出两个字段：

```python
{"triggered": True/False/None, "outcome": "success"/"fail"/"unknown"}
```

评测按「triggered 集合内的二分类」计分，而不是只数 `candidate`。**这是「象+成败」可测的前提。**

**② 断语输出域标签，不输出选项字母**

```
claim → label（如 marriage_stability ∈ {stable, unstable}）
instrument adapter → option（映射到某份题库的选项）
```

映射表必须独立、可审计、可预注册。现在 `tiekoulu_eval.py:76-91` 的 `PREDICTION_MAP` 把映射硬编码在评测工具里——**尺子和被测物混在一起**。

**③ 产品层最便宜的一处修复**

把 `rule_loader.py:354` 的
```python
matched = not failed_conditions and not matched_exclusions
```
改为包含反条件。**但不能直接改**：至少 3 条规则的正/反阈值重叠（正 `>=0.35`、反 `<=0.4`），直接拦会变成「同时成立且不成立」。要先统一「反条件 = 正条件必要前提的否定」这一语义，消除重叠。

**④ 第一个可证伪的窄口：`M2-Y-395`**

「夫妻宫被冲，谁制谁」——方向是**确定性**的，不需要旺衰阈值：

- 触发器：原局存在 `chong` 边且成员含 `D.b`
- 方向：比较本气五行。`KE_MAP[wx(D.b)] == wx(other)` → 我制对方；反之 → 对方制我；有冲无克 → 弃权
- 断语：我制 → 婚姻较好；被制 → 婚姻不好；无克 → 弃权

ChatGPT 6 已跑过（中枢未复核）：两分类 22/59 = 37.3%，同一批 59 题「永远猜 B」= 54.2%，独立期望 37.0%。

**按预注册判据，「方向 alone」已被否证**——说明「制 ≠ 克向」，必须进入「制死/制净」。

### 3.2 Gemini 4 的核心建议

**把证明点从「成败」移到「应期」**，用 `real_cases_990`（415 例可做婚姻应期评测），并先冻结年龄基线（45.2%）。

它让 `G-CY-008`（发财应期六条铁律，现 uncompilable）和 `M2-Y-019`（寻根基三步法，现 uncompilable）从「算不出来」变成「算得出一个年份集合，可判分」。

**但 ChatGPT 6 反对**：「不在原局断语未过基线前接应期——岁运的前提是原局断语成立，原局在 n=236 上仍不过基线，接岁运只会把噪声乘上时间窗。」
