## 3. 本轮新增：第一把「正确性」尺子（T-146）

### 3.1 为什么要造这把尺子

在此之前，项目所有验收指标——开火率（fire rate，断语命中比例）、未知率、锚点准确率（anchor accuracy，引文与原文行号是否对得上）、pytest 通过数——**全部是内部自洽性指标**。

一条完全错误的断语，可以开火率漂亮、未知率合理、锚点全对。

### 3.2 尺子的数据来源

仓库根目录 `tiekoulu_1507_to_1428.json`（铁口箓题库，第 1507 至 1428 期）：

- 每题格式：`[单选题] 日主婚姻状况？` 选项 A/B/C/D/E，`correct_answer`（正确答案）字段

### 3.3 评测方法（已实现，`tools/tiekoulu_eval.py`）

- 出生时刻解析：`line3_true_solar`（真太阳时，已按出生地经度校正）优先，36 期全部成功

- 断语求值：对当前 12 条「已编译」断语逐期求值

- 显著性用置换检验（permutation test，随机重排样本求概率）

## 4. 作者对这个结果的解读（请审查是否成立）

### 4.1 不能过度解读

**这不能证明「断语无效」，只能证明「现有样本量无法证明有效」。**

功效计算（power analysis，单侧 α=0.05，功效 80%）：

| 想检出的差异 | 需要样本 n |
|---|---|
| 婚姻 45.7% → 60%（+14 个百分点） | **75** |
| 婚姻 45.7% → 55%（+9 个百分点） | **178** |
| 职业 67.7% → 80%（+12 个百分点） | 81 |
| 学历 36.4% → 50%（+14 个百分点） | 80 |

现状：婚姻 n=35，断语命中仅 **3–10**。**在 n=10 上做任何调参都是对噪声调参。**

### 4.2 作者认为真正的瓶颈是「测量功效」，不是「断语质量」

理由：如果连「有没有信号」都测不出来，那么改断语、补用神层、加 60 条婚姻断语，全都是盲改。

### 4.3 一个可能被忽略的样本来源

铁口箓 284 期中，**248 期无性别**，含 **2093 道题**：

| 类别 | 有性别 36 期 | 无性别 248 期 | 合计 |
|---|---|---|---|
| 学历 | 36 | 247 | **283** |
| 职业 | 49 | 351 | **400** |
| 家境 | 28 | 198 | **226** |
| 财富 | 23 | 183 | **206** |
| 婚姻 | 36 | 247 | 283（但需性别） |
| 子女 | 64 | 248 | 312（但需性别） |

**关键判断**：性别只影响三件事——大运顺逆（十年一步运的排列方向）、配偶星取法（男命以财为妻、女命以官为夫）、子女星取法（男命以官杀为子、女命以食伤为子）。

**因此学历、职业、家境、财富四类题目，理论上不需要性别。**

但 `engine.api.analyze_facts` 拒绝 `gender=None`（实测报 `ChartInputError`，性别输入错误）。作者设想的绕法：对无性别期**分别按乾（男）与坤（女）各排一次盘，只采纳两次结果一致的断语结论**——若某断语受性别影响，两次结果会不同，即被自动排除。

## 5. 作者的初始方案（格局判断 / geju）

### 5.1 论点（Thesis）

**下一步不是改断语，也不是补用神层，而是先把尺子从 36 期扩到 284 期（针对 4 个不依赖性别的类别），并把断语的「可对照方向」从人工映射改成声明式字段。**

在拿到每类 ≥200 样本之前，任何「改断语」的动作都是对噪声调参。

### 5.2 第二个（更大胆的）论点

**现有断语不是为「可验证」设计的。**

断语说「夫妻宫安静 → 婚姻较好」，题库问「未婚 / 一婚 / 一婚离丧」。两者之间靠人工写的 `PREDICTION_MAP`（方向预测表）搭桥——**这个桥是实验者写的，不是断语本身自带的**。

这意味着：**断语与「可判定的结果」之间没有契约。** 任何断语都能被实验者临时映射到任何选项，测出来的分数反映的是映射者的判断，不是断语的质量。

作者的提议：断语编译时必须自带 `predicts`（预测目标）字段，声明「本断语预测哪类问题的哪些选项」，让评测变成机械比对，而不是人工解释。

### 5.3 三条路径对比

| 路径 | 内容 | 判断 |
|---|---|---|
| **保守路** | 维持 36 期样本，直接改断语 / 补用神层 | ❌ 在 n=10 上做任何改动都是拟合噪声 |
| **干净目标** | 扩到 284 期 + 断语加 `predicts` 声明式字段 + 重跑 | ✅ 推荐 |
| **分阶段干净路** | 先只扩样本（不改断语），拿到真实基线；再决定改不改断语 | ✅ 实际建议走这条 |

### 5.4 第一个证明点（First Proof Point）

扩容后，在样本 n ≥ 200 的类别（学历/职业/家境/财富）上：

- 若有**任何**断语在 p ≤ 0.05 上超过同基数基线 → 信号存在，继续沿断语路线走
- 若**全部**断语仍不超过基线 → 说明问题不在样本量，而在理论建模，需回到用神层重建

### 5.5 推翻条件（Falsifier）

若扩容后所有断语仍不超基线，则本方案（「先扩样本再改断语」）的前提——「样本量是瓶颈」——被推翻，应转向「理论层缺失」。
