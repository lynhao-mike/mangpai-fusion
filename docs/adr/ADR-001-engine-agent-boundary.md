- 相关：[ADR-002](ADR-002-delivery-vs-metric.md)、[ADR-003](ADR-003-claim-conditions-and-school-routing.md)、[契约 23](../../engine/contracts/23-claim-condition-protocol-v1.md)

## 1. 背景

决策 D 写于 v1.2（2026-05），当时的假设是「引擎能把断语跑成结论，AI 只负责话术」。实测已经不支持这个假设：

| 实测事实 | 数字 | 来源 |
|---|---|---|
| 引擎报告渲染层里用硬编码字符串冒充结论 | 22 处（其中 16 处为「待反馈…」） | `META/REFACTOR-BRIEFING-2026-10-20.md` §二 断点 6 |
| 具备六要素（条件/排除/反条件/结论模板/证伪/来源）的生产断语 | 16 条 | `theory/production/`（TD-09 当时记 18 条） |
| A 类盲派候选规则中带机器可读触发条件的 | 414 / 1658，且 414 条内容为中文散文 | 2026-10-26 实测 `theory/{gao,duan,yang,ren}/index.yaml` |
| 1658 条规则在 6 张真实盘上通过的集合种类 | 3 种（理论上限 8 种） | `tasks/T-105/STATUS.md` |
| 盲测 6 个错误中「条件未齐就开火」的比例 | 6 / 6 | `META/blind-baseline-v1-2026-10-18.md` §五 |

同时 `AGENTS.md` 已经把「综合推理、证据权衡与最终裁决」交给 Agent，与决策 D 直接冲突，两套规则同时生效。

## 2. 选项

| 选项 | 内容 | 判断 |
|---|---|---|
| O1 | 保留决策 D：引擎出结论，AI 只润色 | 否。引擎目前产不出结论，只能产桩文本；等于让 Agent 为引擎的空白背书 |
| O2 | 反向：Agent 全权推理，引擎只排盘 | 否。会重新引入「心算关系/编造引用」，且不可审计 |
| **O3** | **分层：引擎出事实 + 候选断语 + 结构性护栏，Agent 做裁决与表达** | **采纳** |

## 3. 决定

1. **引擎（engine）** 只做三件事：
   - 出**确定性事实**（排盘、关系边、能量、格局要件、神煞、岁运）；
   - 出**候选断语**（只出通过前置条件求值的候选，附绑定地址与证伪条件）；
   - 出**结构性护栏**（引用存在性校验、时间窗、高风险失败关闭、未处理分歧标记）。
   引擎**不得**输出未经条件求值的结论，也不得用占位文本充当结论。
2. **断语（claim）** 是**带条件的候选**，不是结论。必须带前置条件、失效条件、证伪条件、来源锚点、流派框架依赖级别（见 [ADR-003](ADR-003-claim-conditions-and-school-routing.md)）。
3. **Agent** 在候选集合内做裁决与表达：可以采信、降级、并列分歧或弃权；必须引用可校验的盘面地址与规则 ID；不得计算事实、不得改写冻结记录、不得把候选写成既成结论。
4. `[AI-polish]` 标记保留，但语义收窄为**仅话术层改写**：不得改动结论、证据与置信度。

## 4. 理由

- 盲测的失败模式是「条件边界」，不是「事实算错」：事实层（`engine.cli`）在 6 个错误案例中给出的关系边全部成立，错在断语被提前点燃。把裁决权交给 Agent 并强制它核对条件，才对症。
- 只扩语料不解决问题：密度对比显示语料不是瓶颈（滴天髓 1.34 条/K、段派 0.09 条/K），瓶颈在过滤与分域。
- 保留引擎的事实与护栏，才能满足「证据链可追溯」这条第一性原则；完全交给 Agent 会失去可审计性。

## 5. 后果

- 引擎的 KPI（关键绩效指标）从「准确率」改为**候选质量**：可求值率、地址绑定率、区分度、语义支持率、假阳性率。
- 准确率只在「引擎 + Agent」系统层测量（见 [ADR-002](ADR-002-delivery-vs-metric.md)）。
- `render_report.py` 及其依赖**不删**（生产链 10+ 处调用），只标记 `legacy`（历史遗留）；入口清单变更需单独授权（`tests/test_project_metadata.py` 精确断言现清单）。
- 新增断语一律 `candidate`（候选）状态，不得自动晋升。

## 6. 证伪条件

在候选质量达标（可求值率 100%、语义支持率 ≥90%）之后，若「有候选」与「无候选」在同一批盲测题上的准确率差异不显著，则本边界不成立，应回到引擎自治或重构候选层。

## 7. 明确不做

- 不做「多流派加权平均」的融合器。
- 不做全局综合评分、固定权重。
- 不在本决策下删除任何生产入口或测试。
