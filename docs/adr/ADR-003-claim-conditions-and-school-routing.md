# ADR-003 · 断语条件化与流派路由协议

- 状态：`accepted`（已接受）
- 日期：2026-10-26
- 决策人：产品负责人（用户）
- 记录：Agent
- 相关：[ADR-001](ADR-001-engine-agent-boundary.md)、[契约 23](../../engine/contracts/23-claim-condition-protocol-v1.md)、[分层决策系统设计](../../plans/layered-decision-system.md)

## 1. 要回答的问题

1. 为什么命理师拿这些理论能断，系统不能？
2. 什么条件下用哪个流派？
3. 什么条件下用哪条断语？
4. 流派之间有没有限定条件——某些断语是否只能在该派整体框架内使用？

## 2. 诊断：人能，是因为人先有「判决」，再选「工具」；系统只有「工具」，没有「判决」

| # | 人怎么做 | 系统现在怎么做 | 后果 |
|---|---|---|---|
| 1 | 先定局：旺衰、格局、体用、气势，再选工具 | 先检索 3699 条断语，再按字面相似度拼 | 互相矛盾的断语同时被引用 |
| 2 | 区分条件层级：盘面事实 / 需先判断 / 语境 | 所有条件都是同一层自然语言 | 分不清「成立」与「待判断」 |
| 3 | 知道断语配套：段派做功要先定体用，子平用神要先定格局，任派应期要先有原局结构 | 语料没写配套，就单拎一条用 | 单打独斗，条件不齐就开火 |
| 4 | 会弃权：「这盘看不出 / 两派打架 / 资料不足」 | 倾向给一个答案 | 盲测 34 次用「平」回避、59 次方向翻转 |
| 5 | 有记忆：记得「这条上次在这类盘上错了」 | 反馈只回到规则命中/失验，不回到条件 | 同一个边界错误反复出现 |
| 6 | 多信号同向才断 | 单条命中就断 | 孤证成断、神煞孤断 |

这六条不是「模型不够聪明」，是**输入结构里缺一层「判据」**。7 月的 [`plans/layered-decision-system.md`](../../plans/layered-decision-system.md) 已经把方向说对了一半——「方向已对，管道装反了」：先让流派发言、再事后追认适用性。当时修了路由，没有修「断语没有条件」这一层。

## 3. 决定：四段协议（先定局、后授权、再条件、最后裁决）

```text
L0 事实层      engine.cli 出的确定性事实（已有）
   ↓
L1 局面/路由层  先判「这盘是什么局」，再决定「谁能发言」
   ↓
L2 断语候选层  只允许被授权的流派发言；每条断语必须带可求值条件
   ↓
L3 结构合法性  框架前置是否成立；不成立则否决或降级
   ↓
L6 裁决层      同向加权、冲突降级、弃权、人话表达
```

### 3.1 L1 局面画像（SituationProfile）

从事实层生成的**盘势对象**，只作路由依据，不作结论：日主强弱分区（得令/得地/得势计数）、阵营计数、格局候选与要件状态、体用与做功候选、寒暖燥湿、通关有无、墓库开闭、空亡落点、冲合强度。

**硬约束**：L1 只输出「盘势 + 路由」，不得输出吉凶结论。

### 3.2 L1 流派路由（SchoolApplicability）

每盘、每问题域产出一份路由表：

```yaml
school: duan
role: lead | co_lead | evidence_only | abstain   # 主审/副主审/仅旁证/弃权
applicable_domains: [事业, 财富]
reasons: [...]        # 依据哪些盘势信号
blockers: [...]       # 缺什么导致不能主审
confidence: 0.0-1.0
falsifier: 若该派主审域内命题的准确率低于辅证派，则路由降级
```

路由的实现复用已有模块 `engine/decision/l1_school_router.py::route_schools()`，**不新造第三套路由**。

### 3.3 流派适用范围初始画像（设计裁决，可被反馈改写）

> 本表是**设计裁决**，不是理论原文；它只决定「默认谁主审」，任何一条都可被反馈证据推翻并记录。

| 流派 | 更适合主审 | 更适合辅证 | 应弃权或降权 |
|---|---|---|---|
| 子平类 | 格局、旺衰、用忌、层级清楚的盘 | 事业、财富、学历、层级判断 | 纯象法细节、人物画像 |
| 滴天髓类 | 气势、寒暖燥湿、调候、全局气机明显 | 格局成败、病药、偏枯 | 具体事件细节 |
| 段建业 | 做功路径、体用、宾主、资源转化明显 | 财运、事业落地 | 做功路径不明显 |
| 杨清娟 | 婚姻、人物画像、暗合、取象明显 | 配偶、关系、家庭细节 | 结构层级判断 |
| 任付红 | 岁运触发、应期、是非判断明显 | 时间窗、触发点验证 | 原局结构未成立时 |
| 高德臣 | 神煞、健康灾厄、学业子女等信号明显 | 健康、灾厄、旁证补强 | 神煞孤证主审大结论 |

### 3.4 断语准入：五要素门槛

一条断语要进入候选（candidate），必须同时具备：

1. **前置条件**：可求值的条件树（见契约 23 的谓词表与三值逻辑）；
2. **失效条件**：出现即撤销本条（如「印为用而被财坏」时的反例）；
3. **证伪条件**：出现什么事实即判定本条错了（可事后核对）；
4. **时间窗**：原局 / 大运 / 流年，哪一层成立；
5. **来源锚点**：`path + line`，可回读原文上下文。

缺任一要素 → 降级为 `reference_only`（仅供参考），**不进候选、不得作为断语出口**。

## 4. 流派整体性约束（回答「能不能单打独斗」）

**能，也不是都能。** 三类框架依赖，逐条标注在断语上：

| 类别 | 定义 | 例子 | 执行点 |
|---|---|---|---|
| `standalone`（独立） | 单条自带条件即可成立 | 「印星空亡，学业难成」（高派单条） | L3 只查自身条件 |
| `requires_school_frame`（需本派框架） | 必须在该派整体判定成立后才可发言 | 段派「做功」需先定体用宾主；子平「用神/忌神」需先定格局成败；任派「应期」需原局结构先成立；滴天髓「顺逆」需先判气势；杨派「取象」需先定宫位与星位 | L3 检查同派 frame 命题是否存在且 `pass`；缺失 → `unknown`，降为 `evidence_only`，不得进 L4 |
| `requires_pair`（需配对） | 必须与配对条件同现才成立 | 「伤官见官」必须核官星有无制化；「财坏印」必须核印是否为用 | L3 求值配对条件；不成立 → `reject` |

**为什么这条重要**：盲测里 6/6 的错误都是把 `requires_school_frame` 的断语当 `standalone` 用（三条件未齐就按凶断、开库前提被跳过、做功效率前提被删）。这不是断语错，是**用法错**。

## 5. 什么条件下用什么断语（执行顺序）

```text
1. 问题域 → 路由表（谁主审、谁旁证、谁弃权）
2. 主审派的候选断语按「时间窗」分层：原局 → 大运 → 流年
3. 每条断语求值：前置条件全真 → 入候选；有 unknown → 标「缺事实」；失效条件为真 → 撤销
4. L3 结构否决：框架前置不成立 → 降级或否决
5. L6 裁决：同向 ≥2 条不同来源才可出主断；单条只可出「倾向」；两派冲突 → 降级表述 + 写明分歧点
6. 出口：断语必须带地址、规则 ID、来源锚点、证伪条件
```

## 6. 验收标准（每批断语条件化都按此验收）

| # | 指标 | 门槛 |
|---|---|---|
| 1 | 可求值率（能给出真/假/未知） | 100%（不再出现「证据不足」静默为假） |
| 2 | 地址绑定率（至少绑定 1 个柱位或关系边） | ≥90% |
| 3 | 区分度（固定 20 张盘上的通过集合种类） | ≥12 种（当前 3 种）；单条开火率 5%–95% |
| 4 | 语义支持率（独立抽样 20 条，原文确实支持） | ≥90% |
| 5 | 路由一致率（与命理师人工判断对比抽样） | ≥80% |
| 6 | 回归 | `pytest -q` 不降；已知 MISS 的事前标记率上升、误拦率不升 |

## 7. 后果

- 断语语料从「文本库」变成「可求值库」；不可条件化的部分明确标 `reference_only`，**不假装可用**。
- 引擎的产出从「结论」变成「候选 + 绑定 + 证伪」，Agent 的裁决才有依据。
- 流派路由成为独立可审计对象，可被反馈逐条推翻。

## 8. 证伪条件

条件化批次完成后，若出现下列任一情况，本协议不成立，需回退重设计：

1. 候选精度没有提升（同题对照，准确率差异不显著）；
2. 语义支持率低于 70%（说明编译出的条件不是原文意思）；
3. 路由一致率低于 60%（说明路由表是拍脑袋的）。

## 9. 明确不做

- 不做全局加权平均、固定权重。
- 不把「多派都发言」当默认。
- 不用「判平」当弃权的替代品。
- 不为凑齐流派而引用无关命中。
