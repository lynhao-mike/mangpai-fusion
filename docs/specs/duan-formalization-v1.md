# 段建业形式化方法 v1（规则/案例/矛盾/留出）

## 1. 分层

| 层 | 整合 | 规则 |
|---|---|---|
| 案例语料 | 22/23/21/19/28 全部 | 带 book/section/line/quote；重复盘/矛盾盘单列 |
| 规则源 | **单源** | 22 系统教材；每条规则注明源书/节/行；不合并同义句 |
| 矛盾 | 单列 | 不平均、不静默选边；ambiguous/excluded/needs_anchor |
| 留出 | 跨书 | 训练 15(22)/留出 25(跨书)；先封、hash |
| 标签 | 单轴 | 先六合靶点；不碰旧 enum |

## 2. 规则 schema

- `when` 只用 engine 可观测**抽象属性**：mechanism、紧贴、月令、透干、争合、克破、闭库、连体；
- 禁具体字对、禁整数党势、禁“旺/有力”、禁浮点；
- `then` 单轴结论；每条带 source_ref + 逐字 quote；
- quote 必须映射 engine 边/地址；映射不上→`unoperationalized`，永不触发；
- 同边两规则相反→`needs_anchor(rule_a,rule_b)`；书有 quote 优先级才可解；
- 弃权在作者已判案例上记 miss；弃权率 >30% 判规则不可操作。

## 3. 标签

- 只收作者**明文结论**；沉默者排除并计数；歧义/同盘反结论→ambiguous；
- A/B 盲抽 + 第三人裁；κ≥0.85；A/B 一致率 ≥90%；
- 每条 quote 逐字可检；训练/留出零重叠；规则作者不读留出。

## 4. 通过/停

- 入口：单轴标签 ≥15；试抽 10 例后 <10 无歧义 → 换轴一次；
- Dev ≥85%；Holdout 一次：≥80% 已决 + 覆盖率 ≥70% + 优于最高频类 +20pp；
- 两轮防泄漏；仍不过即停；显式 <15 换轴一次；不调阈值/不删案例/不换留出。

## 5. 四层顺序（盲派）

① 干支连体/成党 → ② 冲/合/刑形态 → ③ 宾主/体用 → ④ 取象；
前层 <80% 不开后层；T-199 只做②的“合靶点”；T-200 冲等①。

## 6. 不做什么

- 不混书定规则；不平均矛盾；不把 LLM 当运行时裁决；
- 不写具体字对；不压整数党势；不用旧 enum/旧 timing/旧 3 卡；
- 不跑 P2；不改保护区；不重跑 A+60/dev-20/fresh-40。
