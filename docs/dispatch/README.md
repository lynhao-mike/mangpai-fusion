## 每项完成后的动作

1. 子代理写 `tasks/<ID>/BRIEF.md` 与 `STATUS.md`。
2. 回到中枢会话说一句「T-1xx 完成」，中枢会亲自跑：
   ```
   .venv\Scripts\python.exe -m pytest -q
   .venv\Scripts\python.exe -m tools.verify_baseline
   ```
   并对该卡的自证项逐条复现。
3. 中枢验收通过后，更新本表状态，给出下一项的提示词文件。

## 中枢不采信的东西

- 「测试通过」这句话本身。只看退出码与数字。
- 子代理对代码行为的描述。涉及候选集合变化、字段是否存在，一律实跑。
- 任何「为了让测试变绿」的判据改动。发现即打回。
